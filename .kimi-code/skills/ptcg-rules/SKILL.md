# PTCG 规则查询

本项目规则一律以简中官方为事实源，**不凭记忆猜规则**。

## 查询顺序

1. **规则正文**：`docs/rules-manual.md` —— 依简中官网规则页（pokemon.cn/tcg/rules）逐节整理的完整说明书。按章节定位：
   - 卡牌种类/特殊卡种（ex、ACE SPEC 等）→ §1
   - 开局顺序（先攻、起手、mulligan、布阵、奖赏设置）→ §2
   - 区域与信息公开性（哪些区域对谁可见）→ §3
   - 回合结构与行动详则（每回合次数限制）→ §4–5
   - 招式与伤害（计算顺序、弱点/抗性）→ §6
   - 特殊状态（中毒/灼伤/睡眠/麻痹/混乱、宝可梦检查）→ §7
   - 昏厥、奖赏卡、胜负 → §8
2. **引擎落点与决议**：`docs/rules-reference.md` —— 引擎/DSL 实现速查 + 附录 A 规则决议日志（争议规则的历史裁决）。
3. **上游数据口径**：db 项目 `effect_tags.yml` 词表（DSL 词表对齐用）。

两份文档冲突时以 rules-manual.md 为准，差异需进 rules-reference.md 附录 A。

## 硬性纪律

- **术语**：只用简中官方用词（昏厥/奖赏卡/备战区/战斗场……），玩家口语（气绝/奖品）不进文档与代码。
- **信息公开性**：奖赏卡、牌库、手牌为非公开区域——奖赏卡对**双方**都隐藏（含自己不可查）；对手手牌内容对 Agent 不可见。写涉及查看/拿取这些区域的效果前先查 rules-manual §3。
- **规则不猜**：说明书未覆盖的互动（复杂时序、连锁、多张卡效果冲突），不要自行裁决。先查官网规则页/官方 Q&A；仍无定论的，记入 rules-reference.md 附录 A 规则决议日志（日期/议题/决议/出处），并向用户确认。
- **实现带出处**：规则相关的引擎/DSL 实现，测试或注释标注出处（官网规则页节号 / 规则书 / Q&A）。
- **说明书维护**：规则结论有变化（官方改规则、核对出新事实）时同步更新 rules-manual.md，并在附录 A 记一条决议。
