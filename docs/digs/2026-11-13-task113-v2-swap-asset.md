## 装载告警与释义降级披露（重要）

swapA / swapB 的换入卡经 `db.search_cards(name, limit=1)` 解析到 **DSL 定义库未覆盖的印刷**（巢穴球 CBB3C-1902、摔角鹰人 CS1DC-159），装载按 vanilla（无效果）结算并告警；弗图剧本（CSV6C-125）有覆盖、无告警。因此 A/B **不是设计意图的「功能替代」**，实测为：

- A = 「高级球 3→2 + 换入无效果卡」的净检索 −1 检验：**零效应**（连胜负局数都与 baseline 逐局相同，261/239——该刀在这 500 种子上未影响任何决策）。
- B = 「多龙奇 4→3 + 换入无效果卡」：**−6.2pp 显著**——4-of 进化线减一的代价可被 500 局 CRN 口径检出，这是资产的实质敏感性证据。
- C 阴性对照不受影响（设计如预注册）。

## 管线缺口（另立 task 候选，本任务不动码）

swap 语法 `in` 仅支持卡名，换入印刷 = db 首命中、不可指定——**功能替代类换卡需要印刷级控制（`in_id`）**，否则换入卡可能静默退化为 vanilla。当前「告警 + 不视为错误」行为本身合理（同卡多印刷合法），缺的是印刷选择能力。Owner 拍板后另立 task。

## 结论

首个换卡敏感性正式资产成立：阴性对照验证噪声底合格、4-of 引擎件 −1 检出 −6.2pp、检索轴 −1 零效应。所有数字为同模拟器内对比，不构成真实预测。
