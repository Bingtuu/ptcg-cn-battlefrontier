# 冠军差距完整评估 —— 从当前工具到「靠它拿冠军」的距离

- 日期：2026-11-14；触发：Owner「完成度距离冠军差距很大」之问
- 方法：外部同类项目调研（PTCG/MTG 生态）+ 本仓库能力逐项审计 + 实证探针（MCTS vs 启发式）
- 结论口径：本文是战略评估，所有 sim 数字限同模拟器内，不构成真实预测

## 0. 评估框架：冠军需要的能力栈

| 层 | 内容 | 对冠军的贡献 |
|---|---|---|
| L1 数据层 | 真实 meta 的地面真值（卡组级 + 对局级） | 选卡与 tech 的唯一权威依据 |
| L2 引擎层 | 规则正确性、卡池覆盖 | 分析可信度的地基 |
| L3 策略层 | 强 AI 陪练（策略质量标尺 + 训练对手） | 策略改进的载体；「最佳策略」的搜索与验证 |
| L4 分析层 | 选卡优化、败局解剖、决策挖掘、对手建模 | 信息效率：把数据变成可执行的优先级 |
| L5 工作流层 | 工具出先验 → 人肉验证 → 反馈闭环 | 工具价值落地的形式 |
| L6 效度层 | sim → real 转移性 | 天花板：决定以上所有层的数字能否外推 |

**外部调研的三条硬结论**：
1. PTCG AI 策略层的公开前沿是**学习类 agent**（Kaggle 官方赛），手工启发式在任何生态里都不是冠军方案；
2. 「数据驱动备赛」的成熟形态 = **真实对局大数据 + matchup 矩阵 + 选卡优化器**（17lands/metamages 模式），模拟只是辅助；
3. 我们的上游 db 已具备该模式的**原料**（CN 卡组级 + intl 对局级），缺的是**产品层**（ matchup 表可视化、期望胜率选卡器）。

## 3. 实证探针：策略 gap 量化（MCTS 2×50 vs 启发式，火伊布 vs 玛俐，30 局，种子 425000..425029，失败 0，墙钟 8 分钟/16 workers）

**结果：MCTS(A/火伊布) 14 胜 / 启发式(B/玛俐) 16 胜 —— MCTS 侧 46.7%（n=30，CI 约 ±18pp，统计上与掷币无异）。**

对照系：同对局启发式镜像基线火伊布 51.2%（n=2000）——即 **2×50 预算的 MCTS 打这套牌不优于（甚至略逊于）调好门的启发式**。

**三条读数**：
1. **策略差距不能靠「换 MCTS 当标尺」解决**——标准预算下它不是更强的陪练；task 097 的 no-go 与 m14 的小 margin 与此互证；
2. **策略层缺口的本质 = 需要真正更强的策略**（学习类 agent，Kaggle 前沿路径），而不是更多搜索预算——预算路线已被 097 封顶，本探针补上了「现有预算内 MCTS ≠ 更强教练」的直接证据；
3. **方向性 caveat**：单格 30 局功效极弱，本探针证的是「无显著优势」，不是「MCTS 更弱」；但它足以否定「把 MCTS 当冠军陪练」的默认假设。

## 4. 差距到冠军的路线图（按 ROI 排序，假设继续投入）

**A. 分析层补完（小成本，直接服务年底赛）**
- A1 败局解剖产品化：终局类型 × 死亡回合分桶 + 系统回放抽样（协议已在 Owner 三问后设计）；
- A2 metamages 式选卡器：meta share（CN）× matchup 矩阵（intl 7 卡组弱参照 + sim 同口径补全 9 卡组）→ 期望胜率最大化 + 蒙特卡洛 field 模拟 → 「带哪套 + 针对谁」的量化答案；
- A3 决策挖掘入产品流：task 098 的 m14_decision 工具泛化到任意结果库。

**B. 策略层攻关（大成本，真正缩小「陪练差距」）**
- B1 MCTS 成本再评估：M11 评估器已落地（rollout 截断），097 no-go 是「当时预算下」的结论；评估器 + 蒸馏学生做 rollout policy 的混合搜索是否打开新空间，值得一次预注册试点（不是重开 097，是新证据下的新论证）；
- B2 学习类 agent 预研：Kaggle 官方赛证明路径存在；我们的 M12 管线（教师采集→蒸馏）已通，瓶颈是教师质量而非机制——B1 是 B2 的前置。

**C. 数据层（生态位，非工程）**
- C1 CN 对局级：源端不存在，已穷举证明 → 不可修，放弃；
- C2 intl 供给：task 112 值守即可，无动作。

## 5. 诚实底线

1. **冠军差距的大头永远在牌手**——临场、心态、准备深度。工具链的上限是把信息效率和陪练质量做到极致；
2. 即使 A+B 全做完，按 claims register 的效度事实，**任何工具的输出都还是「先验」，人肉验证是闭环中不可省略的一环**——这不是工具的耻辱，是卡牌游戏的本质（对局级真实数据的缺失使纯数据闭环不可能）；
3. 当前完成度对「**辅助**一个认真备赛的牌手」已成立（选卡简报 + 定量调卡 + 结构理解 + 可审计回放）；对「**替代**任何一环冠军级准备」不成立（强陪练缺席 + CN 对局级数据缺席，后者永久）。
