## 1. 研究问题 1：搜索空间

### 1.1 槽位分类（定案）

按 CardDef 机械分类（不引入语义判断），每张印刷（card_id）归一类：

| 槽位 | 判定 | 例（711874） |
|---|---|---|
| 基本能量 | supertype=energy 且 is_basic_energy | 基本水能量 |
| 特殊能量 | supertype=energy 非基本 | 喷射能量 / 璀璨结晶 |
| 进化线位 | supertype=pokemon 且 stage≥1（按 evolution_chain 归组） | 猫头夜鹰（咕咕线）、大比鸟ex |
| 打手单卡位 | supertype=pokemon 且 stage=0（含规则盒 ex/太晶） | 火伊布ex、古剑豹、太乐巴戈斯ex |
| 训练家位 | supertype=trainer | 宝可平板、空手道王的修炼 |

- **换出侧**：每个印刷位均可换出 1 张（`out_count=1`）；换出多份（4→3）与 1-for-1 同为合法刀型，原型只扫 1-for-1（§1.4 范围裁切）。
- **不做**「保护核心卡」硬规则：t1114 人工刀位实证会故意剪进化线（大比鸟ex 1→0 换叶伊布ex），任何「不许拆线」规则都会杀掉真刀位。拆线只记软告警。

### 1.2 候选来源（trade-off 表）

| 来源 | 机制 | 优点 | 缺点 | 原型 |
|---|---|---|---|---|
| (a) 同 archetype 邻近卡组高频单卡 top-N | db `decks.archetype_name` 匹配 → `deck_cards` 频次聚合 | 贴合真实构筑分布；零额外数据管道 | 受 archetype 标注质量限制；近窗沉降期噪声（task 133 警告） | **实现**（默认 top-N=12） |
| (b) 败因触发件（autopsy 输入） | `--autopsy` 败因解剖 → 针对性 in-card 注入 | 把 t1114 的「败因直觉」机械化，方向性最强 | 需要败因→卡映射知识（规则/LLM），易过度拟合单一对局样本 | 半自动：`--include "卡名 [card_id]"` 手填注入（占位，自动映射留正式立项） |
| (c) 跨卡组池内高使用率 top-N | db 全局/池内窗口单卡频次 | 发现 deck 外的 meta 通用件（斗子/能量回收级） | 与目标卡组无关联，绝大多数对不可用，稀释搜索预算 | **不做**（待拍板） |
| (d) 卡组内已有卡的加份 | (a) 天然覆盖（邻近卡组高频件包含已在阵卡） | 支持「火伊布ex 2→3」类加浓刀 | — | 由 (a) 覆盖 |

**定案**：原型 = (a) + (b) 手填。(c) 列为拍板项。

### 1.3 过滤链（定案，顺序即管线）

对每个 (out 印刷, in 印刷) 候选对，依次过滤，拒绝必带 reason（不猜纪律）：

1. **平凡拒绝**：in == out（同印刷无意义）；in-card 与 out-card 同名同印刷。
2. **DSL 覆盖**（task 115 纪律）：换入印刷必须 `classify_dsl == covered`，或豁免（基本能量 / 纯白板宝可梦，与 task 131 strict 口径同源）。vanilla 异文本印刷**拒绝**（防无效果静默退化）。
3. **赛制 + 结构合法**：换后 60 张 card_id 列表过 `db.validate_deck`（装载日期 = 最新 standard 快照 effective_from，与 `load_deck` 同口径）：60 张 / 同名（含同 name_group）≤4 / ACE SPEC ≤1，违规拒绝。
4. **软告警（不拒绝）**：换出后 stage≥1 印刷余量为 0 → 「剪断进化线」告警；换出后卡组基本能量张数 < 10 → 「能量基底偏低」告警。告警进输出头注，不进过滤。

### 1.4 原型范围裁切（定案）

- 只扫 **1-for-1 单卡替换**（一刀一 variant）；多刀组合（如火伊布ex+友好宝芬 双刀）空间 ~O(C²) 暴力不可行，正式立项评估「贪心序贯刀」（迭代：top-1 刀落表后再搜第二轮）。
- 换出 side 固定 = `--deck` 侧（备赛语境：优化我方卡组）。
- 多印刷纪律：in 侧全程 card_id 级（`SwapCfg.in_id`），零名字兜底。**out 侧已知限制**：`SwapCfg.out` 仅卡名，同名多印刷槽位（如 711874 的咕咕 CSV9.5C-141×1 + CSV9C-154×3）换出印刷不可指定——过滤链整槽拒绝并计 reason（不猜纪律），正式立项可加 `out_id`（动 runner 层，超出本任务范围纪律）。
- 跨槽位换（宝可梦位→训练家位）**允许**：t1114 人工刀位实证保护方向即「古剑豹→友好宝芬」跨槽位刀，任何槽位配对口令都会杀掉真刀位。

## 2. 研究问题 2：目标函数与验证标准

### 2.1 目标函数

原型目标 = **vs 指定对手的 A 侧胜率最大化**（`--vs <deck_id>`）。field 期望胜率合成（task 125 `expected_winrate`）是设计推荐方向（§2.5 trade-off），原型不接（保持 CLI 面最小）。

### 2.2 局数档位（定案）

| 档 | 局数/格 | ΔWR 95% CI 半宽（p≈0.3 时） | 用途 |
|---|---|---|---|
| 筛选档 | **100–200** | ±6.5pp（100）/ ±4.6pp（200） | 全空间排序，**只做描述不宣称显著** |
| 确认档 | **2,000**（task 117 口径） | ±2.9pp | top-k 候选的正式判定 |

依据：task 117 实证 2,000 局 CRN 可分辨 ≥3pp 效应、CI 半宽 ≈±3pp；100–200 局档半宽 4.6–6.5pp，足以把 ≥10pp 效应排进前列（§3 假阴性表），±3pp 级小效应本就不该由模拟单独定性（task 117 阴性对照教训）。

### 2.3 显著性门槛（定案）

- 点估计 + CI：ΔWR（variant − baseline）95% CI，非合并 SE——**复用 `report/sensitivity.py` 的 `diff_ci`**（与 task 023/117 全库口径一致，不另写统计）。
- 确认档判定「候选刀位」需同时满足：
  1. **统计**：95% CI 完全在 0 同侧（等价口径下报告 z/p 供复核）；
  2. **实际显著性**：|ΔWR| ≥ **3pp**（= 2,000 局 CI 半宽，低于此值的「显著」是统计功效的 artifact）。
- 演示档（100–500 局）放宽：只排序 + 标 CI，不做「候选刀位」宣称（§6 预注册判据照此写）。

### 2.4 多重比较（trade-off 表 + 推荐）

| 方案 | 机制 | 优点 | 缺点 | 适用 |
|---|---|---|---|---|
| 每比较 α=0.05 | 不做校正 | 功效最高 | k=5 时族假阳性 ≈ 1−0.95⁵ ≈ **22.6%** | 不可单独用 |
| Bonferroni α/k | 确认档 k 个候选 | 族错误 ≤ α 严格 | 保守，k 大时功效塌 | 小 k（≤5）适用 |
| BH (FDR) | 按 p 排序控制 FDR | 功效好于 Bonferroni | 实现与解释成本高；k 小时间 Bonferroni 差异有限 | 大 k / 全空间推断 |
| **两阶段 gatekeeping** | 筛选档**不做 p 值宣称**（纯排序），族错误只在确认档 k 个候选上控制 | 与两阶段架构天然对齐；筛选档几百个候选的「隐性多重比较」不进族 | 依赖筛选档 top-k 覆盖真刀位（§3 假阴性） | **推荐（原型采用：确认档 Bonferroni α/k + BH 敏感性对照列）** |

**定案**：筛选档输出禁含「显著」字样（格式化层强制）；确认档报告 uncorrected p + Bonferroni p_adj(k) + BH p_adj 三列，判定以 Bonferroni 为准。**BH vs 纯 Bonferroni 待 Owner 拍板**（正式批 k>10 时 BH 优势明显）。

### 2.5 目标函数扩展（trade-off 表）

| 目标 | 机制 | 状态 |
|---|---|---|
| vs 单对手 | 本原型 | **定案（原型）** |
| vs field 期望胜率 | `--field` 快照 × sim matchup 格合成（task 125 `expected_winrate`）；每候选需 ×field 对手数的模拟量 | 设计推荐方向，**待拍板**（成本 = 候选数 × field 大小 × 局数） |
| 多对手加权 | 三对手各跑一遍按权汇总 | 演示即此形态（三对手独立报告，不合并） |

## 3. 研究问题 3：两阶段预算分配

### 3.1 预算方程

C = 过滤后候选数；k = 确认档候选数（默认 3）；总预算 B（局）：

```
筛选档：g1 = ⌊B × 60% / (C+1)⌋   （baseline 与每候选同种子区间，CRN 成对）
确认档：g2 = ⌊B × 40% / (k+1)⌋
约束：g1 ≥ 60（低于此排序无意义，报错要求加预算或收窄候选）
```

60/40 分配理由：筛选档要覆盖 C+1 个实验（C 常 ≥100），是预算大头；确认档只有 k+1 个实验但单格局数高（正式档 g2=2,000 时确认档占 (k+1)×2000/(C+1)×200+… ≈ 42% @ C=100，比例自洽）。

### 3.2 假阳性 / 假阴性量化（正态近似，p=0.3）

筛选档噪声 σ₁ = √(p(1−p)·(2/g1))：g1=100 → **±6.5pp**；g1=200 → ±4.6pp。

**假阳性**（零效应候选混进确认档，gatekeeping 后由 Bonferroni 兜底的概率）：

| k | uncorrected α=0.05 | Bonferroni α/k |
|---|---|---|
| 3 | 14.3% | 3.0% |
| 5 | 22.6% | 4.9% |

**假阴性**（真效应 δ 的候选在筛选档被挤出 top-k，C=200、k=5、g1=100/200）：

| 真效应 δ | g1=100 | g1=200 |
|---|---|---|
| ≥10pp | ≈0% | ≈0% |
| 5pp | ~8% | ~2% |
| 3pp | ~55% | ~40% |

（近似：P(挤出头名之外的第 k 名阈值) ≈ Φ((δ−q)/σ₁)，q = top-k 门槛噪声分位；精确值以模拟标定为准，正式立项可钉种子 MC 复核。）

**结论（定案）**：筛选档职责 = 不漏 ≥5pp 效应（100 局 FN ≈8%，可接受）；±3pp 级小效应**本就不该被搜索器单独排序出来**（t1114 实证：人工刀位在 2,000 局下也只有 ±2pp——这类刀的判定靠败因解剖的方向先验 + 确认档，不靠筛选档噪声排序）。因此 §6 交叉验证判据按「方向共现」而非「点估计复现」写。

### 3.3 CRN 成对纪律

两阶段全部实验组同 `seed_start`、同局数（`run_group` 机制天然保证：baseline + variants 同种子区间依次跑）；筛选档与确认档**用不同种子区间**（确认档 seed_start = 筛选档 seed_start + 档内偏移，显式打印），避免同种子复用造成「确认档只是在放大筛选档噪声」的循环论证。

## 6. 预注册判据（2026-11-15 冻结，先于演示跑批）

**E2E 演示配置**：deck = mik_moe:711874；三对手 = mik_moe:711851（多龙黑夜）/ mik_moe:692446（玛俐的长毛巨魔）/ mik_moe:677291（电电虫Box）——即 t1114 三联；基线卡表维持 t1114 原口径；筛选档 200 局/格，确认档 500 局/格，k=3；种子区间与 t1114 不重叠（防任何隐性复用）。

1. **管线完整性**：三对手合计失败局 = 0；过滤链逐 reason 计数落输出（每类拒绝 ≥0 显式列出）；装载零 vanilla 告警（全部 in_id 覆盖印刷，task 115 纪律）。
2. **交叉验证（核心）**：每对手确认档 top-3 ∪ 筛选档 top-10 中，出现 **t1114 同类方向**候选即记命中。方向定义（对应 t1114 人工刀位）：
   - **火伊布 ex 出手保障方向**：换入 ∈ {火伊布ex, 伊布ex}（t1114 败因「败局 80% 火伊布ex 零出手」→ knife-flareon3 / knife-eevee3）；
   - **保护方向**：换入 ∈ {友好宝芬} 或其他防御/干扰类训练家（t1114 knife-bibfin2）。
   判定：**3 对手中 ≥2 命中 = PASS；=1 部分通过；=0 FAIL**（FAIL 同样如实交付并归因）。
3. **量级互证**：演示档净胜点估计与 CI 半宽（±4–7pp）与 t1114 2,000 局口径读数（±2pp 级效应、半宽 ±3pp）量级自洽——即演示档**不期望**复现点估计，只验证方向共现与管线正确性；点估计复现属正式批（2,000 局档）判据。
4. **限定语纪律**：输出头注含「自对局先验」限定语与筛选档「不宣称显著」禁令（测试断言）。

**已知功效局限（诚实声明）**：演示档 200/500 局对 ±2pp 级真效应排序功效 ≈ 掷硬币（§3.2）；判据 2 的「方向共现」是管线验证判据，不是搜索器灵敏度的定量证明——灵敏度定量评估 = 正式立项后钉种子注入已知效应候选的回收率实验（建议预注册进正式任务书）。
