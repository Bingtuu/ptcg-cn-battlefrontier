## 2. 实验设置（零新模拟局）

- **输入**：task 146 标签集（13 组合 × 4 对手 × 2,000 局 = 104,000）+ task 141 基线格（4 × 2,000 = 8,000）+ field-snap-2026-11 权重（四对手内归一：多龙黑夜 .415 / 电电虫 .216 / 玛俐 .202 / 土龙节节 .167）。
- **候选臂**：BT 评级（ Bradley-Terry MLE，MM 迭代确定性求解）注册表 {base, 13 组合, 4 对手}；score = field 加权期望胜率；推荐 = argmax；拒绝规则 = score < score(base)。
- **naive 基线**（冻结）：t141 swap-search 过 Bonferroni 门单刀 ×2 的组合体 = L01，验证值 +4.6pp。
- **预算**：0 新局（纯冻结数据重分析，<2 分钟），符合 PRD 条款 3「不得续命加跑」。

## 3. 估计子修正条款（bug 类，跑批中记录）

初版实现按任务书草案用固定 K=32 顺序 Elo（30 轮），首跑读数 **(a) FAIL**（C01 反超 BASE +6.8pp，top-1 错位 L09）。K 扫描（K=32/8/2 + BT-MLE）实证：K=32 的 C01/BASE 倒置随 K 减小消失、K→0 极限与 BT-MLE 一致（C01 < BASE）——**固定大步长 + 按对手段分组的更新序未收敛到它自身数据的 BT-MLE**，属估计子实现缺陷，不是机制信号，也不是判据变更。修正为 BT-MLE 后重跑，两版读数均留档（`verdict.json.estimator_ksweep`）并并报告。

**对 task 127（Elo 联赛）的前置约束**：联赛评级实现禁用固定大步长顺序 Elo——须 BT-MLE 或小步长 + 交错更新序，并在联赛验收中附收敛性检查。

## 4. 读数与解释

1. **机制判别力成立**：BT 评级 + field 权重的推荐流程在 v1 标签集上完整复现地真值结构——阳性锚 L01 = top-1 且为唯一与 naive 基线重合的推荐；唯一有害组合 C01 全表垫底（score 0.5727 vs BASE 0.5976）且 LOCO 4/4 折上仅凭 3 胞信息即被拦截。
2. **naive 基线的判别价值在结构层**：naive 流程 = 采纳全部过门单刀、无组合复核——若 C01 的两刀以单刀过门（其设计意图），naive 必然产出 −2.4pp 的改表；实测臂演示同一批对局数据 + 一个拒绝规则即可拦截。这正是 PRD 门槛动机（task 141 第 5 环：判别质量必须在地真值上验证）的具象化。
3. **一般性证据**：LOCO held-out Spearman 4/4 为正（0.57~0.87）——3 胞拟合的评级在完全留出的对手格上仍保有排序力；最高折 0.87、最低折 0.57（玛俐格，其格内信号本身最弱：标签 13 组合中 4 个组合在该格为负）。
4. **(b) 的规格解释**（预注册已声明）：「显著优于基线」字面在 v1 标签集构造不可达（正向上限即 L01 本身），以非劣 + 有害规避操作化；若 Owner 认为应维持字面读数，等效结论 = 本标签集无法证明 (b)，需扩面标签集（更多有害类组合）后重验——留 Owner 裁量。
