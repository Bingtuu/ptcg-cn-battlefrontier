## 判读（2026-11-20）：MLP 0.7867 < 0.85 → gate_recalibration（决定性证据：线性 ≈ 非线性）
| 模型（同 560 维特征、同 60 局探针 seed 800000..800059，n=5,354 决策点） | val MSE | v2.x AUC |
|---|---|---|
| ridge v3（task 155 资产，同探针重跑） | 0.1758（20 局冻结 gate 读数 0.7571 = 低抽样实现） | **0.7874** |
| **MLP 560→128→64×1**（3 epoch：0.1732→0.1683→0.1672，未饱和） | 0.1672 | **0.7867** |

**结论**：非线性模型与线性模型在决策点 AUC 上逐位打平（Δ=−0.0007）——**模型类不是瓶颈，560 维特征集的信息天花板 ≈ 0.79**。0.90 门不可达的原因是 v2.x 对局从单方可见视角的不可约随机性（牌库顺序/对手手牌），不是表达力。单配置单种子使 0.7867 成为天花板下界，但线性≈非线性等价是结构级证据：再换模型类也挤不出 +0.11。

**给 Owner 的 gate 校准修订提案**（预注册决策规则触发；改判据 = Owner 级决策）：
1. **主门修订建议**：绝对 AUC ≥ 0.90 → **「同探针协议下 ≥ 天花板参考（MLP 560→128→64）AUC 的 95%」**，附辅助门「显著优于 30 维基线（Δ ≥ +0.05）」。rationale：0.90 是 v1 时代尺子，v2.x 天花板实证 0.79；gate 的本意是「教师种群信号源质量」，天花板比例判据直接服务该本意。按此口径 **ridge v3 立即过门**（0.7874 ≈ 天花板 99.9%，Δ=+0.11 vs 30 维基线）→ task 151/152 解冻。
2. 备选：维持绝对判据但降档（≥0.75）——简单但天花板感知缺失，下一代卡池还得重校准。
3. B（教师去评估器化）在天花板证据下更不必要；C（延期）无新增理由。

## 修订后风险 review（Owner 要求）

1. **天花板绑定**：0.7867 锚定 v2.x 池 × 该对决 × 启发式自对局。换池/新机制批后不重锚 = 判据漂移风险。→ PRD v0.7(a) 重锚协议已钉（门判前必重跑 spike 并记录）。
2. **抽样宽度**：60 个独立结局标签仍小；但三臂同局成对，比例判据噪声主要被对消。→ PRD v0.7(b)：比例落 90–100% 临界带扩 120 局复判（本次 100.1% 属临界带上缘，然 Δ 条件宽裕 +0.076，双条件互为冗余）。
3. **参考是下界**：单配置单种子 MLP；未来更强参考会让旧候选比例虚高（过松方向）。→ 重锚协议要求换代更新参考；同代内参考固定，无漂移面。
4. **泄漏面**：探针种子 800000+ 与训练种子 960000+ 不重叠；训练分布 = 全池 45 对 54k 局，针对单对决 60 局过拟合空间小；双条件（天花板比例 + 基线 Δ）互相约束 Goodhart。→ PRD v0.7(c) 种子纪律条款。
5. **解冻 ≠ BC 成**：天花板 0.79 意味着评估器信号有 ~21% 成对误判，BC 净效应仍由 task 151/152 自身门管理（提升门 vs 纯 MCTS 2×50 基线）。本门只管「教师信号源质量折扣」是否解除——已解除到该特征集允许的上限。
