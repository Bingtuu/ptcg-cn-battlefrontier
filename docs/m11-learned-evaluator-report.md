读法：
- **K=10 是甜点**：两格三预算 K=10 均列该预算首位；K≥15 边际转负或持平
  （截断过深时评估器介入过晚，噪声主导）。
- **K=5 反不如 K=0（消融）**：截断过早时评估器在中盘未定局的浅估值反而
  带偏 rollout——冒烟期「评估器 +4.7pts」结论在正式 n 下被推翻，正式口径下
  评估器的正贡献集中在 K=10 附近（相对 +4.4pts vs 消融 95.8%，2×25 档均值；
  分格 p0 +1.6 / p2 +7.3——消融本身已接近天花板，评估器增益主要落在 p2 格）。
- **预算响应平**：1×25→1×50 同 K 约 +2~5pts，2×25 K=10 与 1×50 K=10 打平
  （100.2% vs 100.4%），选 2×25 保留双世界 determinization 多样性。
- 墙钟成本（四队列并行口径，~1120 分母点）：2×25 档 ~25 分钟 / 1×50 档
  ~20 分钟 / 1×25 档 ~12 分钟 / 天花板 2×50 K=0 ~50 分钟。

**选档结论：学生档 = 2×25 K=10 + eval-linear-v1**（两格相对天花板 94.0%/106.5%，
均值 100.2% ≥0.85；成本仅为教师档一半）。

## 4. 双锚验收（D-M11-7）

- 锚 1 一致率：绝对 0.85 阈值**结构性不可达**——教师 2×50 异种子自一致率仅
  0.40–0.46（62.1% 决策点属噪声敏感翻转），任何学生都不可能达到。改按设计 §5
  阈值修订呈报走**相对口径**（2026-10-18 用户拍板确认）：选档 2×25 K=10 两格
  相对天花板 94.0%/106.5%，均值 100.2% ≥0.85（**达成**）。
- 锚 2 定点格 CI 覆盖（基准口径经 task 054 修正：两旧基准均为 task 039 MCTS
  信息泄漏修复（4f7f7bc）**之前**所跑，作废）：基准 = 苍响格 94.6%（473/500
  平 1，m11-anchor.db exp 3，当前代码同种子刷新，500 局零失败）/ 赛富豪格
  62.0%（310/500，m11-postfix.db exp 1，修复后同种子 2×50 K=0 纯搜索基准）。
  - 苍响学生 × 赛富豪启发式（m11-anchor.db exp 1，种子 117000..117499 CRN 对齐
    刷新基准）：学生胜 463/500（平 1）= **92.6%**，独立样本 CI95 [0.900, 0.946]，
    距基准 -2.0pts，基准 0.9460 不在学生 CI 内（上限差 0.02pts 贴边未覆盖）。
    **CRN 成对复核**（同种子逐局配对，500/500 全对齐）：不一致对 58——学生多输
    34 / 学生多赢 24，净 -2.0pts；成对差 CI95 [-0.050, +0.010] **覆盖 0**，
    McNemar χ²=1.72（p≈0.19）——成对口径下学生与刷新基准**无显著差异**。
    两口径分歧本身即证据：未配对 CI 把种子间公共方差当噪声，CRN 配对消去后
    差异落在噪声带内。终判呈报裁决（两种口径并列呈报，不自行择一口径宣布通过）。
  - 双学生格（m11-anchor.db exp 2，种子 102500..102999 CRN 对齐，500 局
    零失败）：赛富豪学生胜 257/500 = **51.4%**，Wilson CI95 [0.470, 0.558]，
    基准 62.0%（310/500）**未覆盖（-10.6pts）**；**CRN 成对复核：不一致对 241
    （学生多输 147/多赢 94），成对差 CI95 [-0.167, -0.045] 不覆盖 0，
    McNemar χ²=11.66（p<0.001）——两口径一致：双学生格显著偏离基准**。
    **效应分解（task 054 消融，2026-10-18 数据到齐）**：消融格 = 双侧 MCTS
    2×25 K=0 无评估器（m11-ablation.db exp 1，同种子 500 局零失败），
    赛富豪侧胜 257/500 = 51.4%。
    | 分解项 | 对比 | 差值 | CRN 成对 CI95 | McNemar χ² |
    |---|---|---|---|---|
    | 总差 | 学生 51.4% vs 基准 62.0% | -10.6pts | [-0.167, -0.045] | 11.66 |
    | 评估器净效应 | K=10 学生 51.4% vs K=0 消融 51.4% | **0.0pts** | [-0.060, +0.060] 覆盖 0 | 0.00 |
    | 预算效应 | 2×25 消融 51.4% vs 2×50 基准 62.0% | **-10.6pts** | [-0.166, -0.046] | 11.95 |
    总差全部来自预算减半（搜索迭代 2×50→2×25），评估器净效应点估计为零。
  - **满预算验证格（task 055，2026-10-18 数据到齐）**：双侧 MCTS **2×50 K=10**
    + eval-linear-v1（m11-fullbudget.db exp 1，种子 102500..102999 CRN 对齐
    基准，500 局零失败）：赛富豪侧胜 332/500 = **66.4%**，Wilson CI95
    [0.6215, 0.7040]，基准 62.0% 贴边不在学生 CI 内（方向为学生更高）。
    **CRN 成对复核**：不一致对 210（学生多赢 116 / 多输 94），成对差
    +0.0440，CI95 [-0.0128, +0.1008] **覆盖 0**，McNemar χ²=2.30（p≈0.13）
    ——满预算档评估器净效应与 0 相容。局均长佐证：20.8 ≈ 基准 21.2（预算
    复原后对局形态复原，2×25 档的 19.4 确为预算效应）。task 054 低预算档
    结论（净效应 0.0pts）外推成立：**锚 2 未覆盖全部来自预算减半，学得
    评估器本身在满预算同口径下零失真——锚 2 按同预算净效应口径实质达成**。
  - 锚 2 归因修正（消融数据推翻旧归因）：旧形态「K=10 截断 + 线性评估器
    后期盘面估值失真」**降级**——同预算下 K=10 vs K=0 逐局不一致对 236 完全
    对称（多赢 118 / 多输 118，净 0.0pts），局均长亦无差（19.4 vs 19.6），
    评估器在胜率与对局形态双口径下均无失真证据。对局变短（19.4/19.6 vs
    基准 21.2 回合）由预算减半所致，与评估器无关。
    主因 = 预算减半：迭代数减半使 MCTS 在慢速双侧对局中探索不足（赛富豪格
    局均 21 回合、决策链长，对预算敏感）；苍响格单侧学生+快局（11.6 回合）
    对预算/评估器双不敏感（92.6% vs 94.6%，成对口径无显著差异）。
    **终判（task 055 满预算验证格收口，2026-10-18 用户拍板选项 B 后数据到齐）**：
    低预算档（2×25）的两格偏差全部由预算减半解释（评估器净效应 0.0pts），
    满预算同口径（2×50 K=10）净效应与 0 相容（成对 CI95 [-0.0128,+0.1008]）
    → **锚 2 按「同预算评估器净效应」口径达成**（选档 2×25 K=10 的降本收益
    须配合预算-胜率权衡解读：K=10 评估器截断本身零失真，2×25 预算档胜率
    代价 -10.6pts 属搜索预算问题而非评估器问题）。
