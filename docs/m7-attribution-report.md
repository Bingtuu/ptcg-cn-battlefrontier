## 4. 修复清单分类

**Agent 规则项（进 M8，按预期收益排序）：**

1. **A1 代价弃牌方向**：chooser 区分「收益选择」（取高分，现状正确）与「代价支付」（取最低分）——影响面最大、改动最小，惠及所有带 cost 弃牌/弃能卡组
2. **A2 变量伤害入斩杀表**：伤害估算接入 DSL 变量伤害求值（50×手牌能量 / 70×场上能量 / 失败条件置 0）——让淘金潮/极雷轰参与真实斩杀判定
3. **A4 牌库资源管理**：牌库余量低时抑制纯过牌，或 deck_out 风险进 evaluate 权重
4. **A3 囤能例外**：手牌弹药型招式（×弃手牌能量类）在场时，能量附着规则豁免主战手
5. 布阵纪律：非核心低 HP 基础少铺（通用规则，守 D10 不按卡名分支）；攻击优先级前置（无关键展开件时）

**DSL 缺陷**：零。顺手项：`cards/赛富豪ex.yml` 内 D-WP5-1 注释标记可随下次核销批翻账。

**卡表/数据不可修项**：赛富豪 11 能量密度是简中环境真实常态（db 实测 4490 套含 ≥3 赛富豪ex 卡组能量众数 10–13），real 基准同受此约束——不动（换代表卡组违背卡池锁定纪律）；苍响对低 HP 辅助轴的天然狙击克制；real n<100 格（苍响×赛富豪 68、苍响×喷火龙 48、苍响×多龙喷 61）置信心低，建议偏差表未来版本标注。

## 5. D2-3 门控结论与 MCTS 排期

门控触发：Agent 因素解释 5/5 大偏差格（≥半数，远超门槛）。
