## 1. 卡牌种类

来源：basic_rules01。

### 1.1 宝可梦卡

- 用来使用招式攻击对手宝可梦，或承受攻击；每只宝可梦 HP 与招式不同
- 剩余 HP ≤ 0 时宝可梦「昏厥」，无法继续战斗
- 同名卡 1 套卡组最多 4 张
- **进化状态**：一般为 基础 → 1阶进化 → 2阶进化（卡面左上方确认）
- **进化方式**：手牌的基础宝可梦可直接放于场上；进化卡放于其进化来源的场上宝可梦身上
- 一般情况下：刚放到场上的宝可梦当回合不可进化；刚完成进化的宝可梦不可再进化；1阶/2阶进化无法直接放于场上（即自己最初回合无法进化）
- 属性：每只宝可梦有自己的属性，存在弱点/抗性关系（卡面右上方）

### 1.2 能量卡

- 招式与撤退需要能量；能量附着于宝可梦身上使用
- 无色属性没有基本能量；基本能量在卡组中数量不限
- **特殊能量卡**：除视作能量外还可提供其他效果

### 1.3 训练家卡

- **物品卡**：自己回合使用数量不限；从手牌使出并执行效果后放于弃牌区
- **宝可梦道具卡**：放于宝可梦身上保持附着，直到该宝可梦昏厥进弃牌区；每回合使用张数不限，但 1 只宝可梦最多放 1 张，且已放有道具的宝可梦无法改放另一张
- **支援者卡**：自己回合只能使用 1 张；执行效果后放于弃牌区；**先攻玩家最初的回合无法使用**
- **竞技场卡**：对双方生效；自己回合只可使出 1 张；使出后一直放于场上；打出不同名新竞技场时，先前的竞技场放于**其持有者**的弃牌区；与场上同名的竞技场无法使出

### 1.4 特殊卡牌（拥有特别规则）

- **宝可梦 ex / V / VSTAR**：昏厥时对手拿取 2 张奖赏卡（ex 与同名非 ex 互为不同卡名）
- **宝可梦 VMAX / V-UNION**：昏厥时对手拿取 3 张奖赏卡（V-UNION 一期不实现，PRD §6.5）
- **光辉宝可梦**：1 套卡组只能放 1 张
- **「拥有规则的宝可梦」**（标准赛制）：拥有 ex规则 / V规则 / VMAX规则 / VSTAR规则 / V-UNION规则 / 光辉宝可梦规则 的宝可梦的统称——卡面效果提到该词时指这些卡
- 「一击」「连击」「汇流」卡：右上角标记，本身无特别规则，仅供效果引用
- **谜之化石**：特殊训练家卡，可作为基础宝可梦直接放于场上（对战准备时不可放）
- **ACE SPEC**：每卡组限 1 张（构筑校验层；英文规则书 Appendix 3）

## 2. 对战准备（开局完整顺序）

来源：basic_rules02（所需物品）/ basic_rules04（流程）；2026-08-28 用户核对官方规则书确认顺序。

1. 对战前打招呼（握手问好）
2. **猜拳/掷币决定先攻、后攻——赢的一方选择先攻还是后攻**（引擎白板期：胜方固定先攻，选择权归 Agent 层）
3. 卡组充分洗牌后全部反面朝上放于牌库区
4. 从牌库上方抽取 7 张作为初始手牌
5. 放置战斗场宝可梦（背面）；此时检查起手：
   - **mulligan**：若手牌中没有基础宝可梦，将全部手牌给对手查看，对手确认后放回牌库重洗，重新抽 7 张，重复至有基础宝可梦
   - 每次 mulligan 后，**对手可从牌库上方抽取最多与 mulligan 次数相同张数的卡牌加入初始手牌（对手也可选择不抽）**（引擎白板期：自动化默认抽满，选择权归 Agent 层）
   - 若双方都没有基础宝可梦，则双方互相展示、各自洗回重抽
6. 备战区可放任意只基础宝可梦（≤5），同样背面放置；双方完成后**同时翻开**
7. **双方战斗场都有基础宝可梦之后**，各从牌库顶取 6 张，反面朝上置为奖赏卡
8. 先攻玩家回合开始

所需物品（basic_rules02）：60 张卡组（必须刚好 60 张）、宝可梦硬币 1 枚、伤害指示物、中毒/灼伤标记、对战卡垫。硬币物理规则（至少翻转 3 次、掉出视线外重掷）属赛事执行层，模拟不适用。

## 3. 区域与信息公开性

来源：basic_rules03。

| 区域 | 内容 | 公开性 |
|------|------|--------|
| 牌库 | 卡组反面朝上放置；回合开始与效果从此抽牌 | **非公开**：即使自己也无法随意查看 |
| 手牌 | 玩家手中的卡 | 非公开：对手不可查看内容，**数量公开**；双方手牌数量无上限 |
| 奖赏卡 | 6 张**反面朝上**；使对手宝可梦昏厥时拿取 | **非公开：双方均不可查看内容（包括自己）** |
| 战斗场 | 使用/承受招式的区域（战斗宝可梦） | 公开 |
| 备战区 | 可与战斗宝可梦互换的宝可梦（≤5） | 公开 |
| 弃牌区 | 昏厥、使用过的物品/支援者、效果弃置的卡 | 公开 |

- 「自己场上」= 自己的战斗场 + 自己的备战区；「对手场上」同理
- 引伸（决议日志 2026-08-28）：奖赏卡全程背面，**不存在"翻开奖赏卡"的基础规则**；拿取时加入手牌（此时对持有者可见）；「查看奖赏卡」类效果属卡面效果例外

## 4. 回合结构

来源：basic_rules05。

1. **抽牌**：回合开始必须从牌库上方抽 1 张（不看正面）。**抽牌前牌库已无卡 = 败北**；成功抽到最后一张后牌库变空不算败北
2. **自由行动**（任意顺序、任意次数组合，各行动自身限制见 §5）：
   a. 附着能量（每回合 1 张）b. 基础宝可梦放上备战区 c. 使用训练家卡 d. 进化 e. 使用特性 f. 撤退（每回合 1 次）
3. **回合结束**：使用招式后回合结束；无法/不想使用招式时直接宣告结束。**先攻玩家首回合不可使用招式、不可使用支援者卡**
4. **宝可梦检查**（每个回合结束时进行，见 §7.2）

## 5. 行动详则

来源：basic_rules05。

- **能量附着**：手牌能量附着于场上任意宝可梦，每回合 1 张；附着哪种属性、附着给哪只由玩家决定
- **训练家卡使用**：需给对手查看并表明使用之意后执行效果；用完放于弃牌区（支援者每回合 1 张；先攻首回合不可用）
- **进化**：见 §1.1（当回合出场/已进化锁定）
- **特性**：自己回合选择使用，需向对手表明；发动条件各异（战斗场/备战区/手牌均有）；**一般使用特性不结束回合，但部分特性的使用会直接结束回合**（读卡面说明）
- **撤退**：**每回合 1 次机会**；将战斗宝可梦身上撤退费用数量的能量放于弃牌区后与 1 只备战宝可梦互换；撤退费用**不限属性**；备战区无宝可梦则无法撤退；撤退后剩余能量与伤害指示物保留，**特殊状态与身上附加的效果消除**

## 6. 招式与伤害

来源：basic_rules05。

- **能量需求**：招式按卡面能量符号需求（属性 + 数量；无色需求任意属性可抵）
- **伤害落点**：如无特别说明，招式伤害施加于对手的战斗宝可梦
- **伤害计算顺序**（依次）：
  1. 招式基准值（按招式右方数字与说明文字计算；算出 ≤0 则伤害计算终止，不造成伤害）
  2. **攻击方**身上附加的影响伤害的效果（道具/训练家卡/上一回合招式效果等）
  3. **弱点**：受伤害宝可梦的弱点属性与攻击方属性相同 → 伤害倍增（×2）
  4. **抗性**：抗性属性相同 → 伤害减少卡面数值（-30 等）
  5. **防御方**身上附加的影响伤害的效果
- 伤害以伤害指示物累计放置

## 7. 特殊状态

来源：basic_rules07。

### 7.1 总则

- 五种：中毒 / 灼伤 / 睡眠 / 麻痹 / 混乱
- **叠加与替代**：中毒、灼伤可与任意其他特殊状态叠加；睡眠 / 麻痹 / 混乱三者互相替代（陷入其中一种新状态时，原有的睡眠/麻痹/混乱被替代）
- **恢复途径**：回到备战区（撤退或效果）；进化；使用恢复类效果
- 表示法（实体卡）：中毒/灼伤放标记；睡眠/麻痹横置；混乱倒置——模拟中由状态字段承载

### 7.2 宝可梦检查（每回合结束时）

1. **中毒**：放 1 个「10」伤害指示物
2. **灼伤**：放 2 个「10」伤害指示物，然后持有者掷 1 次硬币——正面灼伤恢复，反面持续
3. **睡眠**：持有者掷 1 次硬币——正面恢复，反面持续
4. **麻痹**：在**其持有者下一个自己回合结束后**的宝可梦检查时直接恢复
5. 需在宝可梦检查时生效的特性/训练家卡效果，此时处理
- 注：特殊状态、特性、训练家卡在检查时的处理顺序可由玩家自行决定
- **检查结束后、下一回合开始前**：剩余 HP ≤ 0 的宝可梦昏厥，对方拿取相应奖赏卡

### 7.3 各状态明细

| 状态 | 行动限制 | 检查阶段行为 | 可撤退？ |
|------|----------|--------------|----------|
| 中毒 | 无 | 放 1 个「10」指示物 | 可 |
| 灼伤 | 无 | 放 2 个「10」指示物 + 掷币正面恢复 | 可 |
| 睡眠 | 不能用招式、**不能撤退** | 掷币正面恢复 | 不可 |
| 麻痹 | 下一个自己回合不能用招式、不能撤退 | 该回合结束后的检查时自动恢复 | 不可（麻痹期间） |
| 混乱 | 无撤退限制 | （不在检查阶段结算） | 可 |

- **混乱**（2026-08-28 用户核对官方规则书 + basic_rules07）：处于混乱的宝可梦**决定使用招式后**，持有者掷 1 次硬币——正面：正常使出招式（混乱不解除）；反面：招式失败并在该宝可梦身上放 3 个「10」伤害指示物。「招式失败」= 并未成功使用招式、不算作使用了招式（如 GX 招式不计为已用）。混乱只对战斗场宝可梦生效

## 8. 昏厥、奖赏卡与胜负

来源：basic_rules06。

- **昏厥**：宝可梦因招式伤害 / 招式效果 / 训练家卡效果 / 特殊状态伤害等导致剩余 HP ≤ 0 即昏厥
- **对手宝可梦昏厥**：自己在**不看正面**的前提下将相应张数自己的奖赏卡加入手牌；**奖赏卡可按任意顺序拿取**；特别规则宝可梦按记述数量拿取（ex/V/VSTAR=2，VMAX/V-UNION=3）
- **自己宝可梦昏厥**：昏厥的宝可梦及放于其身上的所有卡（进化链、能量、道具）放于弃牌区；若昏厥的是战斗宝可梦，需将 1 只备战宝可梦放上战斗场
- **胜利条件**：①拿完全部自己的奖赏卡；②使对手战斗宝可梦昏厥且对手备战区无可换上宝可梦；③对手回合开始抽牌前牌库无卡；④对手主动认输（引擎不模拟认输，记为赛事/交互层）
- 平局情形（双方同时达成胜利条件等）见英文规则书 Advanced Rules「What if both players win at the same time?」——引擎以 `is_draw` + 统计 0.5 口径承载（对齐 db matchup）
