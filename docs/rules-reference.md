## 1. 游戏准备 ✅（2026-08-28 用户核对官方规则书）

完整顺序（官方口径，用户核对确认）：

1. **掷币定先攻/后攻**
2. 双方各抽 7 张起手；手中无基础宝可梦 → mulligan：给对手看过手牌、放回牌库重洗、重抽 7 张，重复至有基础宝可梦；**对手可按我方 mulligan 次数多抽最多等量手牌，也可不抽**（mulligan 处理时执行，选择权属 Agent 层，白板期自动化）
3. 战斗场放 1 只基础宝可梦，备战区可放任意只（≤5），**背面放置、双方完成后同时翻开**（翻开前对手的布阵内容互不可见）
4. **双方战斗场都有基础宝可梦之后**，从牌库顶取 6 张背面置为奖赏卡（引擎实现：双方 setup 完成后统一设置——备战区放置不抽牌，奖赏构成等价）。**奖赏卡为背面朝上，对双方都是非公开信息，翻开前任何人（含自己）不可查看**

- 卡组 60 张；同名卡最多 4 张（基本能量除外）；**ACE SPEC 每卡组限 1 张**（构筑校验层，对齐 db 项目 `validate_deck`）

## 2. 回合结构 🔲

- 回合 = 抽牌阶段 → 行动阶段（自由序）→ 攻击阶段（用招式则回合结束）→ 回合结束检查
- 回合开始抽 1 张（**含全场第一回合**）；无牌可抽时判负（见 §5）
- **先攻方第一回合：不能使用招式、不能使用支援者**（现行规则）

## 3. 行动阶段（自由序）🔲

- **放置基础宝可梦**到备战区（≤5），不限次
- **进化**：手牌进化卡覆盖到对应宝可梦（`evolves_from` 名字链）；每只每回合限 1 次；登场当回合与已进化当回合不可再进化；进化后特殊状态恢复、伤害指示物保留
- **能量附着**：每回合限 1 张，附着到场上任意宝可梦
- **物品卡**：不限次数 ✅（task 003 骨架外，M2 落地）
- **支援者卡**：每回合限 1 张（先攻首回合不可用，见 §2）
- **竞技场卡**：每回合限 1 张；不得打出与场上同名的竞技场；打出新场时旧场进弃牌堆（顶替）
- **道具（宝可梦道具）**：每只宝可梦限挂 1 个；随宝可梦昏厥一并弃置
- **撤退**：弃掉战斗宝可梦身上撤退费用数量的能量，与备战区 1 只对换；撤退方特殊状态恢复；**每回合限撤退 1 次** ✅（2026-08-28 核对官网规则页 basic_rules05；task 004 引擎已实现 `retreated_this_turn` 守卫）
- 特性（Ability）：按卡面标注的时机使用；`once_per_turn` 类限制由 DSL 触发器表达

## 4. 攻击与伤害 🔲

- 使用招式需满足能量需求（数量 + 属性；无色需求任意能量可抵）
- 伤害 = 招式基准值 ± 修饰（弱点 ×2 / 抗性 -30 等；白板期只有固定伤害）
- 伤害以伤害指示物累计；累计伤害 ≥ HP 即**昏厥**
- 特殊状态：中毒 / 灼伤 / 睡眠 / 麻痹 / 混乱；回合间检查阶段结算（中毒/灼伤放指示物，睡眠/麻痹/混乱涉及掷币与行动限制）——白板期无触发源，M2 随效果落地
- **混乱** ✅（2026-08-28 用户核对官方规则书）：只对战斗场宝可梦生效；混乱宝可梦使用招式时掷 1 次硬币——正面：招式正常发动（混乱**不**解除）；反面：招式发动失败（不产生任何招式效果），并给这只宝可梦放 3 个伤害指示物（因此自伤昏厥时正常结算昏厥/奖赏）。撤退/进化仍按 §3 解除特殊状态

## 5. 昏厥、奖赏与胜负 ✅（task 003 已实现骨架）

- 昏厥：整叠（进化链 + 附着能量/道具）进弃牌堆；对手拿奖赏卡（ex 等特殊卡按卡面多拿，白板期恒 1）；**拿取时不看正面、可按任意顺序从奖赏卡区拿取**（奖赏卡对双方均为非公开信息）
- 昏厥方须从备战区换上 1 只；无可换上则判负
- 三种胜利条件：①拿完 6 张奖赏卡（立即获胜）；②对手场上无宝可梦；③对手回合开始无牌可抽
- 平局：双方同时达成胜利条件等情形；统计口径计 0.5（对齐 db 项目 matchup 矩阵）

## 6. 规则骨架 vs 卡牌内容的边界

引擎只实现上述骨架；"这张卡做什么"（含物品/支援者/竞技场/道具/特性/招式文本）全部由 DSL 定义、解释器执行（PRD §5）。训练家卡与 ACE SPEC 的骨架规划见 PRD §6.6。
