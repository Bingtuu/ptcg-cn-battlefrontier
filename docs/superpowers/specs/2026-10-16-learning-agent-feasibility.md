# 学习类 Agent（方向 A）可行性预研报告

- 日期：2026-10-16
- 任务：`tasks/task 047.md`（零代码调研，验收标准见其「验收标准」节）
- 上游定位：一期 PRD D3（启发式 → MCTS → RL 分层，接口预留）；二期 PRD D2-1（RL = 远期观察项，前提「MCTS 后仍有结构性差距且样本成本可承受」）；方向 B 设计文档 §1（调优 = 方向 A 的最小可行第一步与对照基线）
- 性质：可行性结论 + 范式建议；**不构成三期立项**（立项与否 = 用户拍板）

## 0. 结论先行

**有条件可行，推荐路线 = 「学得评估器先行 → MCTS 行为蒸馏跟进」两步走**：

1. **第一步（小成本验证）**：学得线性/小型评估器，接入 MCTS rollout 截断与候选排序——task 046 刚实证评估函数五因子是「死维度」（不接决策面），这个插槽是现成的；数据用启发式自我对局（约 35 分钟可产 10 万局），numpy 级实现即可，全部硬约束天然兼容。
2. **第二步（主线）**：以 MCTS 为教师做行为蒸馏（task 042 的 `mcts_consider` 访问分布已在事件流里，训练信号现成），目标不是「比 MCTS 更强」，而是**让 MCTS 口径的决策质量以启发式的成本例行化**（当前全 matrix MCTS 铺开 ≈68.7h 不适合例行；蒸馏成功则校准矩阵可整体升到 MCTS 口径）。
3. 端到端 self-play RL 与模仿人类学习均判否（理由见 Q2）。

关键前置认知（Q1）：**本项目的学习目标是「拟合 MCTS 教师 + 校准不回归」，不是 ELO 最大化**——这与常规 RL 实践相反，由 task 046 D-046-5 实证（更强 ≠ 更贴合 meta）。

## 1. Q1 目标函数：打赢 vs 像人

证据链：

| 证据 | 出处 | 含义 |
|---|---|---|
| 启发式修复抬升操作质量，加权 \|Δ\| 反而 13.2%→15.0% | task 032（M8b） | 操作质量与 meta 贴合非单调正相关 |
| MCTS 上线后 5/5 重点格大幅提升，2 格精确命中真实值、2 格反超 | task 035（M8c） | 原偏差主因是 sim 侧太弱；拉到人类水平即贴合；个别格疑似超人 |
| MCTS 增强版偏差表加权 \|Δ\| 9.7%，\|Δ\|≥25% 五格归因全闭环 | task 036（M10） | 「MCTS 后仍有结构性差距」这一 RL 前提已大幅弱化 |
| 调优参数双门槛过线（打赢默认）但复校准 \|Δ\| 15.0%→16.1% 恶化 | task 046（D-046-5） | 「打赢」目标与「贴合 meta」目标系统性偏离的直接实证 |

分析：校准偏差与 Agent 强度的关系是**以人类水平为顶点的倒 U**——太弱（M6 启发式）和太强（个别 MCTS 格反超、task 046 过保护参数）都拉大 |Δ|。当前 MCTS(2×50) 大致落在顶点附近（M10 证据）。因此：

- 若学习目标 = ELO/胜率最大化：产出超人 Agent，对卡组强度测试（项目北极星）是负资产，只对「强度上限探索」有研究价值。
- 若学习目标 = 拟合强教师（MCTS）行为：产出的是「平价 MCTS」，直接服务校准管线（MCTS 口径例行化），且不引入「比教师更强」的偏离风险。

**裁决建议**：方向 A 的目标函数钉死为「蒸馏 MCTS 教师 + 复校准 |Δ| 不回归」双锚；胜率/ELO 只作过程指标不作验收指标。最终裁决权属用户。

## 2. Q2 范式选型

### 候选 ① expert iteration / MCTS 行为蒸馏（推荐主线）

- 机制：MCTS 跑局时经 `mcts_consider` 观测事件记录（可见状态摘要 → 根节点访问分布），离线训练策略模型拟合该分布（或 argmax 行动）；推理侧作为新 Agent type 接入统一 `observe` 接口。
- 数据管道现状：task 042 已把访问分布入事件流（events_hash 排除、行为零变化），**训练信号的采集侧已上线**，缺的是状态特征化与训练器。
- 收益：MCTS 口径决策的例行化（matrix 校准从 68.7h 级降到分钟级）；失败兜底明确（蒸馏不达标就继续用 MCTS 定点口径，现状不亏）。
- 风险：状态特征化是主要工程量（牌面由 DSL 数据驱动，可用 card_id 嵌入 + 计数特征；无需理解效果语义——教师已把语义折算进行动分布）；模型容量不足则只能学到教师平均水平（可接受，仍优于启发式）。

### 候选 ② 学得评估器接 MCTS rollout（推荐先行验证）

- 机制：学一个局面评估函数 V(state)（线性或小型 MLP），替换/增强 MCTS rollout 的「打到底」——浅截断 + V 估值，或 rollout 内候选排序。
- 对症：task 035 预算标定的结论「加预算不经济，瓶颈在 rollout 质量」；task 046 刚发现评估函数五因子不接决策面是死维度——**插槽现成、问题已诊断、解药就是学习**。
- 已有素材：`agent/dsl_estimate.py`（281 行纯函数）的变量伤害估算特征可直接复用为特征层的一部分；胜负标签从对局结局回传播放（outcome regression / TD 思路，实现从简）。
- 验收可测：MCTS+评估器在更低预算下对 `mcts_consider` 决策一致率 vs 纯 2×50，及复校准 |Δ| 不回归。
- 定位：学习管线的端到端最小验证（数据→训练→接入→验收全链走通），同时本身有独立收益。

### 候选 ③ 端到端 self-play RL（判否）

- 从零 self-play 的策略搜索在本项目证据下不成立：M8c 证明搜索预算加深到 400u 才 54.2% 且边际递减未平台化，说明该状态空间下「搜索」远不如「先验策略质量」；RL 从零攒先验的样本需求比 MCTS 教师路线高数个数量级（Q3 测算）。
- 目标函数不适配（Q1）：self-play 的天然终点是超人策略，与校准目标相反。
- 判定：否。若未来重做，前提 = 蒸馏线已证明学习管线端到端可行且目标函数问题有解。

### 候选 ④ 模仿人类学习（判否）

- 无数据源：db 侧只有赛果与卡表，无逐手 replay；官方小程序 Q&A 供给此前已判搁置（2026-09-07）。
- 判定：否（供给侧不存在，非技术问题）。

## 3. Q3 样本成本测算

既有实测锚点（STATUS/任务档）：启发式对局 18,000 局 / 6m15s @16 workers（task 030，≈48 局/s 聚合 ≈ 0.33 worker·s/局）；MCTS 标准档 2×50 ≈135s/局/worker（task 034 的 219s 经 task 037 -38.5%）；单局决策点 ≈55（task 042：4 局 219 点）；MCTS 成本模型 ≈2.7s/rollout 单位 + 每局固定开销（task 035）。

| 范式 | 数据需求估算 | 单机墙钟 @16 workers | 判定 |
|---|---|---|---|
| ②学得评估器（启发式自对局 + 结局回归） | 10⁵ 局量级（线性/小模型特征回归的常规充足量） | 10 万局 ≈ 35 分钟 | **廉价，可反复迭代** |
| ①MCTS 蒸馏（教师数据采集） | 10⁴ 局量级 ≈ 55 万决策样本 | 10⁴×135s/16 ≈ **23.4h**（一次性，可接受；增量补数按日批） | 边界可行 |
| ③self-play RL 从零 | 10⁶–10⁷ 局起步（文献惯例下限，且需 MCTS 级评估防退化） | 启发式速度也要 6–60 小时/轮 × 训练轮数不可控；评估另算 | **不经济，否** |

注：①的 23.4h 是按全量 MCTS 决策点采集；若只在「高熵决策点」（task 042 报告已有归一化熵分节）采集或降教师预算，成本可再降一个量级——属实施期优化项。

## 5. 最终建议

**可行，两步走**（②先行小步验证 → ①主线跟进），三期设计要点草案：

1. **三期定位**：学习线以「MCTS 口径例行化」为北极星指标（复校准 |Δ| 不劣于 M10 增强版 9.7% 且 matrix 全量 MCTS 口径成本降到可例行），ELO/胜率不作验收。
2. **M-A（先行）**：学得评估器 v1——特征层（复用 dsl_estimate 特征 + 五因子现状量）、启发式自对局 10 万局数据、线性/小模型回归、接入 MCTS rollout 截断；验收 = 降预算 MCTS 决策一致率 + 复校准不回归。
3. **M-B（主线）**：MCTS 蒸馏——教师数据采集批（~23h 一次性）、状态特征化（card_id 嵌入 + 计数特征）、策略模型训练（依赖调和方案先行拍板）、新 Agent type 接入、验收 = matrix 复校准 |Δ| vs M10 增强版。
4. **依赖开口裁决项**：torch 是否允许作 dev-only 训练依赖（推理纯 numpy）——不批则模型规模受限为 numpy 可训范围，路线不变。
5. **YAGNI 边界**：不做 self-play 从零、不做人类模仿（无数据）、不做卡组构筑学习（方向 C 已否）、不调 MCTS 超参（D-035-5 定案）。

若用户裁决不做：本线重启条件 = ①卡池 v2 落地后 MCTS 口径校准需求变大（全量 MCTS 成本压力再现）；或 ②出现新的结构性偏差且 MCTS 加深预算仍不收敛（D-035-5 口径的复现）。

## 6. 风险与开放项

- **蒸馏天花板**：学生至多学到教师在可见视图下的平均水平；MCTS 教师自身在个别格疑似超人（M8c 反超格），蒸馏可能继承——验收锚定「不劣于 M10 增强版」而非「等于教师」。
- **特征化盲区**：DSL 效果语义不进入特征（引擎零硬编码纪律的延伸），模型对稀有卡牌交互的泛化无保证——卡池 v2 换血后需重训（与调优复跑口径一致）。
- **过拟合卡池**：同方向 B §8 既有口径，9 套池外泛化无保证。
- **开放项**：教师预算档（2×50 标准 vs 4×100 深档教师，成本差 ~3 倍）与采集规模（10⁴ vs 10³ 先行试点）留三期设计拍板。
