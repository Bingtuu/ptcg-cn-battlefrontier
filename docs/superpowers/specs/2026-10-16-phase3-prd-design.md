## 1. 背景与定位

一期回答「能不能模拟」，二期回答「模拟得有多准」。三期回答「**准的口径能不能例行化**」：M10 已证明 MCTS 口径把加权 |Δ| 压到 9.7%，但全 matrix MCTS 铺开 ≈68.7h（task 034 实测）不适合例行——三期用学习方法把 MCTS 口径的决策质量压到启发式成本。

核心资产盘点（三期起点）：

- MCTS 多世界 determinized UCT（task 034，信息泄漏已修复 task 039）+ 预算档定案（标准 2×50 / 深档 4×100+，D-035-5）
- **教师信号管道已上线**：`mcts_consider` 观测事件（task 042，根节点访问分布入流、events_hash 排除、行为零变化）
- 学习评估 harness 现成：tune 子包 CRN 种子协议 + 训练/holdout 分层划分 + D-046-1 双门槛（task 045/046）
- 特征层素材：`agent/dsl_estimate.py`（281 行纯函数，变量伤害/斩杀估算特征）+ `evaluate` 五因子现状量；task 046 实证五因子当前不接决策面 = 学得评估器的现成插槽
- 校准基线族：M6（13.2%）/ M9（15.0%）/ M10 增强版（9.7%），复算入口齐备

目标函数（三期一切的锚，task 047 Q1 结论）：**拟合 MCTS 教师 + 复校准 |Δ| 不回归**。
偏差-强度是倒 U（证据链 M8b/M8c/M10/D-046-5），超人 Agent 对卡组强度测试是负资产；
ELO/胜率只作过程指标，不作验收指标。

## 3. 工作线范围

### 3.1 M11 学得评估器（先行）

**目标**：学习管线端到端最小验证（数据 → 训练 → 接入 → 验收全链走通）+ 直接收益（MCTS rollout 截断降本）。

- 数据：启发式自我对局 ~10 万局（≈35min @16 workers，task 047 测算），局面-结局标签对；种子区间进实验定义钉死
- 特征层：复用 dsl_estimate 既有特征 + evaluate 五因子现状量 + 局面计数特征；全部从 VisibleGameState 抽取（信息纪律）
- 模型：线性/小型模型，numpy 级实现（D3-3：不引学习框架）
- 接入点：MCTS rollout 浅截断 + V 估值（替换「打到底」），或 rollout 内候选排序；以 AgentCfg params 增量接入，默认参数路径零变化（events_hash 回归纪律）
- 验收口径（D3-2 双锚细化，任务书定稿）：①降预算 MCTS+评估器 vs 纯 2×50 的 mcts_consider argmax 决策一致率；②复校准加权 |Δ| 不劣于 9.7%（容差任务书定）；③全量测试 + ruff + 确定性硬验收延续

### 3.2 M12 MCTS 行为蒸馏（主线，门控于 M11）

**目标**：MCTS 口径决策以启发式成本例行化——全 matrix MCTS 口径从 ≈68.7h 降到可例行量级。

- 教师数据：MCTS 标准档跑批采集 mcts_consider 决策点（~55 点/局，task 042 实测）；采集规模与教师预算档（2×50 vs 4×100，成本差 ~3 倍）留 M12 任务书拍板；预研估算 10⁴ 局 ≈ 23.4h @16 workers（一次性），高熵决策点定向采集可再降量级
- 状态特征化：card_id 嵌入 + 计数特征（DSL 语义不入特征，引擎零硬编码纪律延伸）；可见视图 + 合法行动掩码
- 模型与依赖：torch dev-only 开口裁决（D3-3 推迟项）先行；推理侧纯 numpy 前向，权重进版本控制（D3-4）
- 接入：新 Agent type（`type: distilled` 预登记）走统一 observe 接口；与启发式/MCTS 可混编对照
- 验收口径：①matrix 复校准（学生双侧）加权 |Δ| 不劣于 9.7%；②学生 vs 教师决策一致率（任务书定阈值）；③全 matrix 学生口径跑批墙钟 ≤ 启发式口径同量级（分钟级）

### 3.3 卡池 v2 独立线（可选并行，不阻塞主线）

- 复用一期 task 024 流程（WUR 驱动 + 替补补位机制）；db 前置调研数据已就绪（task 044：新冒头 archetype 电电虫Box / 火伊布猫头夜鹰 / N的索罗亚克）
- 与学习线的关系：学习线在 v1 上验收（D3-5）；v2 锁定后调优与学习模型均需复跑（方向 B §8 口径延续）

## 6. 验收策略

- 一期/二期硬验收全部延续（全量 pytest 绿 + ruff 零告警 + 串并确定性 + 主库只读），每 task 收口必过
- 学习线专属双锚（D3-2）：决策一致率（mcts_consider argmax 口径）+ 复校准 |Δ| 不回归
- 训练数据与评估全部走 tune 子包 CRN 协议（同区间跨候选降方差）；模型权重进版本控制（D3-4）
- 复校准对照基线族：M6 13.2% / M9 15.0% / M10 增强版 9.7%（meta 回显三版本轨迹）
