### 2.2 前场：`pokemon_score`、放置、撤退

`pokemon_score`（104–112 行）= `w_hp×HP + w_damage×印面最大伤害 + w_retreat×撤退费`。默认 1 / 5 / −10。只用通用字段（D10）。它同时喂给布阵、推备、能量目标、chooser、以及 `evaluate` 的场面因子。

`tests/test_features.py` 把默认公式手算锁死（妙蛙种子 160、妙蛙草 290）。**改这个函数会拖动 M11 特征对拍和局面评估。** 本规划不改公式（D-078-3）。

`_pick_place`（318–320 行）在 `place_active` 和开局 `place_bench` 上取 `pokemon_score` 最大、iid 最小。开局只能放基础。假说 B：手里同时有高印面伤害的基础、和一条进化线的基础时，高伤基础会当前场。沙奈朵线的基础是拉鲁拉丝，愿增猿是另一张基础。本会话没有印面 HP，所以**不能**断言愿增猿的分数一定更高——实现 078 之前用本机库打印这两张的 HP / 伤害 / 撤退费再算一次分。若愿增猿分更高，假说 B 解释开局；若不是，开局主因在别处，078 的布阵条款就不要为这个格子硬改。

`_pick_promote`（328–332 行）同样按 `pokemon_score`。沙奈朵ex 的 190 伤进这个公式之后，分数会高于 60 伤的基础。假说 C：换上本来就会优先已进化的沙奈朵；「愿增猿一直打」更可能是它没昏厥、所以根本没走到 promote。078 **不改** `_pick_promote`，除非红测证明它在「备战有更高分进化体」时仍选低分基础。

`_pick_retreat`（612–635 行）只在战斗场**每一招都付不起**、且备战有已经付得起的打手时才撤。假说 D：精神幻觉一旦付清（夹具费用两能），这个函数返回 None，备战上已经付清的奇迹之力不会被换上来。`_decide_main` 里撤退排在非斩杀攻击之前，所以只要这里返回撤退，同回合就不会先打出 60。验证 = 计划里的红测：60 伤付得起、不斩杀，备战 190 付得起且斩杀，今天的 `observe` 不撤退。

进化行动本身排在能量和攻击之前（428–432 行），合法就按进化卡的 `pokemon_score` 取最高。假说 E：220/500 不是「进化行动被跳过」，而是线没上场或对局在二阶之前结束。078 的布阵条款若让线的基础更早上场，这个数才有机会动；只改撤退，只影响线已经在备战且付得起的那些局。

### 2.3 能量：先喂战斗场上任何没付清的招式

`_pick_energy_attach`（578–610 行）：战斗场只要还有**任何一招**印面费用没付清，附着就给战斗场；否则给备战里还没付清、`pokemon_score` 最高的那只；都付清了就跳过。手牌弹药型（淘金潮形态）且已经能打时不附着，这是 D-032-5，要保留。

费用检查是引擎自由函数 `_energy_satisfied`（`core.py` 约 111 行），吃的是印面 `atk.cost`。D-WP8-5（附录 A，2026-09-20 已核）：Agent 这三处不读 `provide_energy`，合法性由引擎枚举保证。`modify_attack_cost`（血月按奖赏减【无】）同样不在这三处里。假说 F：纯真火焰四能没付清时，莱希拉姆会一直被当成「还需要能量」，即使力量愤怒已经能打、备战有人差一张就能斩杀。假说 G：血月印面五【无】，奖赏减免之后引擎已经允许宣言，启发式仍觉得没付清。G 是否造成「血月只有约 4%」要先看附着事件的 `detail.target`，不要先改费用模型。

077 已经写了 `_energy_role` / `_mon_energy_role`（225–250 行）：再附一张是「刚好付清 / 只推进 / 没用」。它们只服务特性附伤，**手牌附着没走这条**。079 应复用这个区分，而不是再写一套费用匹配。

### 2.4 同体招式与复制目标

`estimate_attack_damage`（`dsl_estimate.py`）遇到未知计数词返回 None，`_attack_table` 就退回印面 `atk.damage`。`_visible_counter`（约 107–148 行）**没有** `opponent_discard_basic_energy_count`。这个词在 `primitives.py` 约 1231 行，读的是对手弃牌区基本能量；`VisibleOpponentState.discard` 对 Agent 公开（`state.py` 约 266–276 行）。假说 H：复燃的真实 30×N 没进攻击表，印面基值（多半是 30 或 0，本会话未读 db）低于焚身加农炮的 90，于是两招都付得起时选 90，并把能量弃光。验证：对手弃牌区 4 张基本能量时，估算应为 120，`_pick_attack` 应选复燃那一招。这是可见信息补全，不是新规则。

暗夜王牌没有 damage 节点。若它是该卡唯一招式，`_pick_attack` 在「索罗亚克正在攻击」时没有第二招可选。假说 I：约 34% 的触及率主要是它没在场或【恶】【恶】没付清（078/079），不是招式下标。080 不把「提高暗夜王牌触及率」当成自己的主验收。

复制是两段选择（`primitives.py` `_copy_attack_from_bench`，约 2013–2066 行）：先 `own_bench`，再 `anchored_pokemon_attack`。`_pick_choose`（336–390 行）按 `pokemon_score` 给**卡**打分。假说 J：第一段会偏向印面伤害/HP 高的供体（莱希拉姆 170 很容易赢过分），即使它的招式斩杀不了、另一只可以。第二段的 `choices` 是招式下标，按卡 iid 去查会落空，分数变 0，tie-break 取下标最小。`PendingChoice.payload` 在构建时等于 `NeedChoice.carry`（`chooser.py` 把 `payload=need.carry`），第二段的 carry 是供体 iid——这是读代码得到的传递关系，单测要断言 `pending_choice.pool` 与 `payload`，对不上就改读法，不要猜。

混乱本身会拖长对局（攻击失败 + 自伤），但「有 60 伤就别打、改 end_turn」是另一类策略。end_turn 已证伪为主因。080 在只有扰乱招式可打时仍然打，不把停手当成质量。

### 2.5 主阶段顺序（三刀怎么叠）

`_decide_main` 的相关顺序：特性 → 进化 → **附着** → 斩杀攻击 → 道具 → **撤退** → 物品 → 支援者 → 竞技场 → 非斩杀攻击 → end_turn。

同一回合里能量先于撤退。079 决定这张能量贴到谁，078 再决定要不要换人，然后才攻击。三刀的单测互不调用；局级胜率会混在一起。所以拆任务、各自留消融开关，本机 100 局按顺序各跑一次，才能看出是哪一刀在动。
