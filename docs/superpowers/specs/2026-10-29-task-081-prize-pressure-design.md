## 2. 代码现状：哪些假说已经被读代码杀掉

行号会漂，以符号为准。下面每条要么是读 `battlefrontier/agent/heuristic.py` 得到的事实，要么标明「假说」。假说成立与否，由计划里的红测决定。错了就丢掉，不要为了凑 WP 把已杀掉的机制写回去。

### 2.1 事实：行动梯子不读奖赏数

`observe` 走到 `_decide_main`，全程不调用 `evaluate`。`factor_prize_diff`（约 136–138 行）只进 `evaluate`，而 `evaluate` 不参与这一层的行动选择。`view.own.prizes_count` / `view.opponent.prizes_count` 对 Agent 可见（`state.py` 的 `visible_state`，奖赏张数 = 剩余张数），但选攻击、撤退、promote、支援者时都不用它。

`factor_prize_diff` 的注释写「对手奖赏剩得少 = 我方领先」，公式是 `own.prizes_count - opponent.prizes_count`。对手剩得少时这个差为正，按规则那是我方落后（对手更接近拿满 6 张）。`tests/test_features.py` 把这个差值对拍钉死。**本刀不改这个函数、不改它的注释、不改 `w_prize_diff`。** 行动层要判断落后，写 `own.prizes_count > opponent.prizes_count`，不要写 `factor_prize_diff > 0` 当作领先。

### 2.2 事实：战斗场自己能斩杀时，已经会先打

`_decide_main`（约 551–604 行）的相关顺序：

特性 → 进化 → 附着 → **斩杀攻击** → 道具 → 撤退 → 物品 → 支援者 → 竞技场 → **非斩杀攻击** → `end_turn`。

`_lethal_attack`（约 920–934 行）在道具 / 支援者 / 非斩杀攻击之前。当前战斗场的攻击表里，有效伤害 ≥ 对手剩余 HP 且 `lethal_ok` 时，直接打出。假说「能拿奖却不按攻击」对**战斗场自己的招式**不成立。本刀不改这条优先级，不把非斩杀攻击挪到支援者前面。

主阶段每次 `observe` 只返回一个行动，引擎再回来问下一次。所以「支援者排在非斩杀攻击前面」的意思是同一回合先打支援者、回头再攻击，不是把攻击吃掉。假说「支援者挤掉了暗夜王牌，所以同回合打不出来」过宽。它只在更早的行动把战斗场换走时成立（撤退、换人的支援者）。本刀不给支援者做效果分类，不排 gust。

### 2.3 事实：非斩杀的软压力停在「谁都能付得起就不换」

`_pick_retreat`（约 795–819 行）：`board_quality_gate` 开时，战斗场已付清且能斩杀则不撤；否则合法撤退目标里已付清且能斩杀的，按伤害高、bench 下标小换上；谁都不能斩杀则回到 `_pick_retreat_powerless`（付不起才撤）。

因此：战斗场 30 伤付得起、备战 120 伤付得起、对手剩余 200，两边都不斩杀，今天不撤，回头打 30。078 故意把「差多少伤害才值得撤」挡在外面，避免新的魔法数。本刀若要动，只能用已经可见的布尔条件（落后、伤害严格更高），不新增整数阈值。

`_pick_promote`（约 380–384 行）仍只按 `pokemon_score`。公式是 `w_hp×HP + w_damage×印面最大伤害 + w_retreat×撤退费`，**不看能量、不看对手剩余 HP**。印面伤害高的空能量宝可梦会压过印面伤害低、但已经付清且能斩杀的那只。`w_damage` 默认 5，所以「高 HP 低伤墙」要压过「低 HP 刚好斩杀」才成立；计划里的红测按这个手算配分，不要用 200 印面去跟 10 印面比（080 的复制测试已经写过：印面 200 会让分反过来）。

`_pick_attack`（约 936–953 行）无斩杀时取有效伤害最高，tie 取下标小。牌库保护排除含 draw 的招式（D-032-6）保持。没有「这一击值几张奖」的分支。攻击目标只有当前战斗场，奖赏张数由对手那只的规则盒决定，启发式选不了打谁。那是支援者的事，本刀不做。

### 2.4 事实：暗夜王牌在攻击表里是 0 伤

`cards/N的索罗亚克ex.yml`：特性「交易」+ 招式「暗夜王牌」，效果只有 `copy_attack selector=own_bench_attack`，没有 damage 节点。`estimate_attack_damage` 走到步骤末尾找不到 `damage` 就返回 None（`dsl_estimate.py` 约 201 行）。`_attack_table` 对 None 回退 `atk.damage or 0`。仓库注释与 078 规格都写「无伤害数字」。本会话没有打开 `ptcg-cn.db` 核对印刷栏。红测用 stub `damage=None`，不依赖 db。若印刷栏不是空，实现时改读法，不要猜一个伤害数字填进表。

后果：

- `_lethal_attack` 看不见「备战供体被复制后能斩杀」。0 ≥ 剩余 HP 只在对手已经 0 血时成立。
- `_pick_retreat` 同样看不见。备战自己的招式若已付清且能斩杀，078 会把索罗亚克撤下去，本回合攻击的是换上来的那只，不是暗夜王牌。
- 供体自己付不起能量时，撤退的斩杀分支不触发（`_max_paid_ko_damage` 要印面费用已满足）。复制不需要再付供体的费用（`primitives.py` `_copy_attack` 的注释：「作为这个招式使用」）。所以「索罗亚克付了【恶】【恶】、供体没能量、复制能斩杀」今天既不进斩杀分支，也不撤退，而是先走物品/支援者，再以 0 伤招式进入 080 的 chooser。chooser 本身已按斩杀排供体。

080 的 `attack_quality_gate` 只改 `_pick_choose` 的两段，不改攻击表。矩阵上触及后胜率仍贴着整体 sim。**再改 `_copy_donor_key` 不立项。** 假说「选错供体」降成残留：实现时若 100 局事件里，复制选择明显避开了能斩杀的供体，停下来写进结果，不要在本刀顺手改 080。

血月：`cards/月月熊 赫月ex.yml` 是 `passive_static` + `modify_attack_cost`，减免 = `opponent_taken_prizes` 个【无】。079 的 `_pick_energy_attach` 注释写明费用仍是印面。全行触及 9–16/500 与「启发式按 5 费堆能量」相容，但是不是低胜率的原因，本刀不证。**Q4 维持否。** 不写计划里的减费任务。

`play_stadium` / `end_turn` 在 077 已证伪为主因。非斩杀攻击本来就在它们后面，同一回合仍会攻击。本刀不许把它们捡回来当主杠杆。

### D-081-5 WP A 的行为（`prize_pressure_gate` 开）

落后：`view.own.prizes_count > view.opponent.prizes_count`。双方都是 6，或我方剩余更少（领先），本包不触发。

1. **撤退。** 先走 078：战斗场已能斩杀则不撤；备战已能斩杀则撤到那个目标。两边都不能斩杀时，若落后，且某个合法撤退目标的已付清有效伤害**严格高于**战斗场，撤到伤害最高的那个，平手 bench 下标小。伤害口径沿用 `_max_paid_ko_damage`（最高已付清、`lethal_ok` 的有效伤害；斩杀与否由调用方和剩余 HP 比）。没有严格更高的目标：回到付不起才撤。
2. **promote。** 落后，且对手战斗场存在时：备战里把该只当成战斗场后、已付清招式能斩杀当前对手的，优先于纯 `pokemon_score`。多个则伤害高者优先，再 `pokemon_score`，再下标小。没有这种候选，或对手战斗场为空：与今天相同。
3. **斩杀、能量、开局、特性、非斩杀攻击的排序：** 不改。WP A 加回归：未落后时，30 伤前场对 120 伤备战、谁都不斩杀，仍然攻击不撤退；promote 在未落后时仍取 `pokemon_score` 更高者。

`copy_lethal_gate` 也开时，上面的「有效伤害」含 D-081-6 的一层复制前瞻。这样不会把「复制出去比备战自己打更高」的战斗场换成备战。`copy_lethal_gate` 关时，复制仍是 0，落后就会按 0 去和备战比。这是两个开关的定义，不是意外。

开关关：1 和 2 都回到今天。

### D-081-6 WP B 的行为（`copy_lethal_gate` 开）

只处理战斗场上一招已经付清印面费用、其 `on_attack` 扁平步骤里有 `copy_attack`，且 `selector=own_bench_attack` 的情况。其他 selector（例如对手战斗场那一招）维持印面。读不到文档、步骤里没有这个 action、或 filter 求值抛 `DslError`：不猜，维持印面。

前瞻：备战里 `matches_in_play` 通过该节点 `filters` 的供体，用现有 `_copied_strike` 取最高一击（能斩杀的伤害优先进入「能否斩杀」的比较；伤害数字取这些供体上的最大有效伤害）。供体不需要自己付得起那一招的费用。只看一层，不把供体招式里的又一次 `copy_attack` 展开。费用仍是印面 `_energy_satisfied`（D-WP8-5），不读 `modify_attack_cost`。

这一跳写进两处，不写进 `_attack_table`，因此不改 `_pick_attack` 的非斩杀排序：

1. `_lethal_attack`：该招式下标按前瞻伤害参与「能否斩杀」。能斩杀则走今天的斩杀优先（先于撤退、物品、支援者、竞技场）。多个斩杀仍取伤害高、下标小。
2. `_max_paid_ko_damage`：同一前瞻并进「战斗场最高已付清有效伤害」。078 的「战斗场已能斩杀则不撤」因此看见复制。WP A 的高低伤比较也看见复制。

代价要写清楚：一旦被当成斩杀，这一回合还没打出的支援者 / 物品 / 竞技场会被跳过。这是今天真斩杀已有的政策（`test_lethal_beats_supporter`），不是新政策。复制斩杀套用它。若这让 100 局变差，结果里写「WP B 消融」，不要把支援者重新插回斩杀前面。

`_pick_choose` / `attack_quality_gate` / `opponent_discard_basic_energy_count` 保持 080。开关关：上面两处都回到印面 0。

索罗亚克只有暗夜王牌一招。非斩杀路径仍可能在「复制不斩杀、旁边还有印面更高的第二招」时选第二招。第一刀不改。红测不要用双招复制卡要求非斩杀路径选复制。
