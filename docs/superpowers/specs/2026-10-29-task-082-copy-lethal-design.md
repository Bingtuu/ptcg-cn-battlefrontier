## 2. 代码现状

### 2.1 事实：暗夜王牌在攻击表里是 0 伤

`cards/N的索罗亚克ex.yml` 的「暗夜王牌」只有 `copy_attack selector=own_bench_attack`，没有 damage 节点。`estimate_attack_damage` 找不到 `damage` 就返回 None。`_attack_table` 对 None 回退 `atk.damage or 0`。仓库注释写「无伤害数字」。本会话没有打开 `ptcg-cn.db`。红测用 stub `damage=None`。若印刷栏不是空，实现时改读法，不要猜一个数字填进表。

后果：

- `_lethal_attack` 看不见「备战供体被复制后能击杀」。0 伤不会因为对手还活着而算击杀。
- `_pick_retreat` 同样看不见。备战自己的招式若已付清且能击杀，078 会把复制手撤下去。本回合打的是换上来的那只，不是暗夜王牌。
- 供体自己付不起费用时，撤退的击杀分支不触发。复制不需要再付供体的费用（`primitives.py`：作为这个招式使用）。于是今天先走物品和支援者，再以 0 伤招式进入 080 的选择。

080 的 `_pick_choose` 不改攻击表。**再改 `_copy_donor_key` 不立项。** 100 局事件里若复制选择明显避开了能击杀的供体，写进结果，不要在本刀顺手改 080。

### 2.2 事实：战斗场自己的印面招式能击杀时，已经会先打

`_lethal_attack` 在撤退和支援者之前。这条对**印面或估算已经有伤害**的招式成立。082 只补「复制招式在表里是 0、供体其实能击杀」这一种。不把普通的非击杀攻击挪到支援者前面。

一旦复制被当成击杀，这一回合还没打出的支援者、物品、竞技场会被跳过。这是今天真击杀已有的政策（`test_lethal_beats_supporter`）。082 套用它，不新开一套排序。

### 2.3 已丢掉、本刀不做

- 战斗场印面招式能击杀却去发育：不成立，见 2.2。
- 开场、能量是主杠杆：078–079 已做，行扫描胜负几乎持平。不改 `_pick_energy_attach`、`_place_key`。
- 血月减费：Q4 维持否。
- `end_turn` / `play_stadium`：维持证伪，不改位置。
- 落后时换高输出、promote 优先能击杀的备战：那是 task 081 的 `prize_pressure_gate`。082 不实现 `_prize_behind`，不新增这个字段。

### 2.4 假说（未证）

把「已付清的 `copy_attack`，合法供体里最高的一击」算进战斗场的击杀判定之后，该打暗夜王牌拿奖的回合会走现有的击杀优先，并且不会因为备战自己也能击杀而先撤退。这不一定提高触及后的胜率。触及后仍输，可能是拿了一张奖、对手用 ex 拿两张。单测只锁决策。

## 3. 决策草案

### D-082-1 范围只有复制招式击杀前瞻

不实现 081。不把两次 100 局合成一条有效带。

### D-082-2 不写卡名

允许用的通用字段：HP、印面伤害、印面费用、`owner`、DSL 的 `copy_attack` 及其 `filters`（`matches_in_play`；未知 filter 抛 `DslError` 时不猜，该招式维持印面）。

**卡名例外清单：空。** `owner_pokemon:N` 来自那张卡自己的 DSL，不是 `if name ==`。

### D-082-3 `pokemon_score` 与 `factor_prize_diff` 冻结

与 081 相同。`tests/test_features.py` 期望不改。

### D-082-4 一个开关，不进 tune

| 字段 | 默认 | `False` 时 |
|---|---|---|
| `copy_lethal_gate` | True | 复制招式在击杀判定和撤退里仍按印面（`None` → 0） |

不进 tune 的 10 维。`bool_fields` 补上该字段，`len(search_space())` 仍是 10。不新增整数阈值。

### D-082-5 行为（开关开）

只处理战斗场上一招已经付清印面费用、其 `on_attack` 里有 `copy_attack` 且 `selector=own_bench_attack` 的情况。其他 selector 维持印面。读不到文档、没有这个 action、或 filter 求值失败：不猜，维持印面。

前瞻：备战里通过 `filters` 的供体，用现有 `_copied_strike` 取一击。有 `ko` 为真的，伤害取这些里的最大，击杀为真；否则伤害取全部最大，击杀为假。不要再乘一次弱点。供体不需要自己付得起那一招。只看一层，不展开供体招式里的又一次 `copy_attack`。费用仍是印面 `_energy_satisfied`（D-WP8-5）。

写进两处，不写进 `_attack_table`，因此不改 `_pick_attack` 的非击杀排序：

1. `_lethal_attack`：该下标按前瞻参与「能否击杀」。能击杀则走今天的击杀优先。多个击杀仍取伤害高、下标小。
2. `_max_paid_ko_damage`：同一前瞻并进「战斗场最高已付清有效伤害」。078 的「战斗场已能击杀则不撤」因此看得见复制。

若 081 已经在树上，`prize_pressure_gate` 的高低伤比较会读到这个伤害。082 不去实现落后换人。交互测试只在该字段已经存在时跑，见计划。081 还没有合入时，不要在 082 里加上 `prize_pressure_gate`。

`_pick_choose` / `attack_quality_gate` / 复燃计数保持 080。开关关：上面两处都回到印面 0。

索罗亚克只有暗夜王牌一招。非击杀路径在「复制不击杀、旁边还有印面更高的第二招」时仍选第二招。第一刀不改。红测不要用双招复制卡要求非击杀路径选复制。
