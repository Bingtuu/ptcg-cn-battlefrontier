### 2.1 主阶段顺序

`_decide_main`：特性 → 进化 → 附能量 → **`_lethal_attack`** → 附道具 → 撤退 → 物品 `min(iid)` → 支援者 `min(iid)` → 竞技场 → **`_pick_attack`** → `end_turn`。

`can_ko` 为真时攻击先于训练家（084 Q2=C）。这是必须维持的。

### 2.2 攻击序，对证据卡是空操作

N的索罗亚克ex 只有「暗夜王牌」一条，`damage` 为空，效果是 `copy_attack` / `own_bench_attack` / `owner_pokemon:N`（`cards/N的索罗亚克ex.yml`）。`_pick_attack` 在这只身体上没有第二招可排。085 已经记下这一点。特性序在斩杀之前，dig 里触及后攻击/特性次数翻倍的是 **A 侧**（负局 A attack 5.92 / ability 5.31，胜局 2.11 / 2.21）。那是对手发动机，不是 B 把自己的特性排错。本刀不改 `_pick_ability`，也不为了这一格去改 `_pick_attack` 的招式下标。

### 2.3 供体选择已经「能 KO 就 KO」，而且只看战斗场

080 的 `attack_quality_gate`：`_copy_donor_key` / `_copy_attack_key` 经 `_copied_strike`，对**对手战斗场**先 `can_ko` 再最高伤害。供体不必自己付费。

证据卡组里挂了 DSL 的 N 供体（卡面事实，实现仍禁止卡名分支）：

| 招式 | 伤害落点 |
|---|---|
| 莱希拉姆 力量愤怒 / 纯真火焰 | 对手战斗场（纯真火焰无效果节点，引擎打战斗场） |
| 达摩狒狒 复燃 | `opponent_active` |
| 达摩狒狒 焚身加农炮 | 战斗场 90，然后弃自己能量，再 `opponent_bench` 90 |

主伤害没有「选哪只对手」这一步。首触不转化，若 080 工作正常，含义是：**当时没有任何已付清复制能打死当前战斗场**。重排招式下标改变不了这件事。

### 2.4 对手目标选择仍是高战力分

`_pick_choose` 只对 `pool=="own_bench"` 的复制供体、以及 `anchored_pokemon_attack` 走 080 的 KO 键。其余宝可梦选择，包括 `opponent_bench`（老大的指令的 `switch`，以及焚身的备战 90）和 `opponent_pokemon_any`，落到 `pokemon_score` 最高者。

`pokemon_score` = HP + 印面最高伤害 + 撤退费惩罚。最高分倾向厚墙，不是「这一下打得死的那只」。

`switch` 的挂起池就是 `opponent_bench`（`primitives._switch`）。支援者本身仍按 `min(iid)` 决定打不打得出。本刀默认**不**改「打哪张支援者」，只改「这张已经在问目标时选谁」。

### 2.5 奖杯完成没有任何行动消费者

昏厥拿奖在引擎：`PRIZE_BY_RULE_BOX`（`ex`/`V`/`VSTAR`=2，`VMAX`=3，其余 1），奖赏拿空即 `reason="prizes"` 获胜。启发式行动选择不读这张表。`factor_prize_diff` 只进 `evaluate`，083 起冻结，`observe` 不叫它。`prize_race_gate` 只在非斩杀撤退/换上读「剩余奖赏谁多」，不读「这一击拿几张、能不能收完」。

因此「奖杯完成」若要存在，只能作为**多个可 KO 目标之间的第二键**。战斗场固定、且这一下打死不了它时，奖张键不触发。

### 2.6 086 已经占了「落后则换人」

`_prize_race_behind` = `own.prizes_count > opponent.prizes_count`。落后且复制可见时，撤退/换上只允许更高的复制前瞻，禁止更高印面（081 反例）。该门在 dig 所用的库上对 A69 零增量。本刀不往这个函数加行为。

## 6. 与 dig 的冲突（不猜掉）

1. dig 结构表一行写「首触时 B 已落后」计数 **0**、种子列空。同一文的对照表、命名澄清和 STATUS 写 **39/52**。本文采用 **39/52**。0 那一行是分类漏计，不是「没有落后局」。
