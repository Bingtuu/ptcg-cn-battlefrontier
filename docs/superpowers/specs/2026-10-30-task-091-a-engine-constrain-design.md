## 3. 建议机制

### 3.1 L — 领先时节流循环特性（本文建议）

字段 `leader_cycle_throttle_gate`（默认 True，不进 tune）。

当门开且同时：

1. `_lethal_attack` 候选为空（本步没有斩杀攻击可取）；
2. `view.own.prizes_count < view.opponent.prizes_count`（己方剩余奖更少 = 领先；与 086「落后」相反）；
3. 该 `use_ability` 经 `_is_cycle_discard_draw` 判定为交易类循环；

则本步不发该特性（`_pick_ability` 视作价值 0 / 跳过），继续后续排序。非循环特性、斩杀攻击、落后或打平侧：行为不变。
