## 2. 代码现状（main `76021ee`，以符号为准）

行号会漂。读 `battlefrontier/agent/heuristic.py`。本节是调查，不是实现。

### 2.1 主阶段没有 `place_bench`

`_decide_main` 的顺序：特性 → 进化 → 附能量 → **`_lethal_attack`** → 附道具 → 撤退 → 物品 `min(iid)` → 支援者 `min(iid)` → 竞技场 → **`_pick_attack`** → `end_turn`。

`place_bench` 只出现在开局 `_decide_setup_bench`。行动阶段合法列表里的 `place_bench` 今天没有任何消费者。

`can_ko` 为真时 `_lethal_attack` 先于训练家与攻击返回（084 Q2=C）。R 插在最后的 `_pick_attack` 之前，斩杀已经返回过的局面到不了这里。

### 2.2 复制伤害为 0 时今天仍会挥

`_one_layer_copy`：没有合格供体时返回 None；有供体但最高伤害是 0 时返回 `(0, False)`。`_lookahead_on_active` 在 None 时退回印面表。复制招式印面伤害为空，表上是 0，`via="print"`。`_pick_attack` 在无斩杀时取有效伤害最高的一招；身体上只有这一招时，0 伤也会打出。

`_copied_strike` 读供体卡面的估算，None 则回退印面。供体不必自己付能量。弱点用**宣言方**（当前战斗场）的属性。

### 2.3 已占住的分支

`_pick_retreat` 在备战换上后 `can_ko`、或复制伤害严格更高时已经会撤（含 086 的落后分支）。R 不进这个函数。`_pick_choose`、`_pick_promote`、`_pick_ability`、支援者 `min(iid)` 都不改。

## 3. 建议机制

启用窗口（四条同时为真）：

1. **时序**：`view.own.prizes_count > view.opponent.prizes_count`（落后）。打平或领先不启用。
2. **零转化挥击**：今天的 `_decide_main` 正要返回 `attack`；`_ko_prize_lookahead.can_ko` 为假；该招的效果是一层 `copy_attack` + `selector=own_bench_attack`（读 DSL）；有效伤害为 0。有效伤害：`via=="copy"` 时用 `best_damage`，否则用印面表（复制返回 None 时就是 0）。`best_damage>0` 的芯片挥击不启用。
3. **手里有供体**：某个合法 `place_bench` 的基础，临时看成无能量、无伤害的在场宝可梦，用现成的 `matches_in_play` 对上这一招 `copy_attack` 节点的 `filters`，并且 `_copied_strike` 的最高伤害 **> 0**。战斗场保持现在这只，供体不换成战斗场。过滤读不懂、或没有一张伤害 >0：不放，维持今天的攻击。
4. **会改选**：R 打出该 `place_bench`。今天这条路径打出的是攻击，所以人选不同。

多张基础都合格：`_copied_strike` 伤害高者优先，平手 `iid` 小。

### 3.1 R — 落后且零伤复制时，先放供体基础（本文建议的唯一行为）

字段 `convert_timing_hybrid_gate`（默认 True，不进 tune）。关闸时 `_decide_main` 与今天相同。

只在 §2.1 的最后一档攻击之前插入。特性、进化、附能、斩杀、道具、撤退、物品、支援者、竞技场的现有顺序都不变。已经决定打支援者或撤退的回合，R 看不到。

实现时不要递归调用 `_decide_main` 来探测「正要返回攻击」。插入点就在攻击档：前面的分支都没返回，合法攻击非空，`_pick_attack` 将选出的那一招满足第 2 条。

`_lethal_attack` 不改。`_pick_attack` 不改。`_pick_choose` 不改。`_pick_promote` 不改。`_pick_retreat` 不改。`_pick_ability` 不改。

诚实边界：R 只替换「已经走到 0 伤复制攻击」的那一步。它不把战斗场上即将被打昏的身体换下去，所以「少送奖」在本刀里是**启用窗口**（已经落后才发育供体），动作本身是让下一拍复制有机会打出 >0 的伤害。满血厚 ex 打不死、可见伤害估计为 0 的那种 089 局势，R 不依赖它。若 236 局里这种「落后 + 0 伤挥击 + 手里有合格基础」很少，Q3 失败，本任务收口。
