claims register「换卡敏感性」行当前是「有代码无正式资产」：task 075 交付了 variants 跑批 + `bfsim sensitivity --out` 双轨报告 + 回放样本，但 STATUS（task 072 节）明确「换卡正式 `results/*swap*` 未见，只有模板和代码」。本任务补首个正式资产，并用**阴性对照**自证 pipeline 噪声底——这正是本项目预注册 + 证伪文化的标准动作。

## 3. 预注册协议（判据冻结于跑批前）

### 3.1 数据

- base + 3 variants，各 500 局，**同种子区间**（CRN 成对，对齐 v2 矩阵口径）；启发式 agent；16 workers；结果库 `results/v2-swap-dragapult.db`。
- 实验定义入版本控制：`experiments/v2-swap-dragapult-dusknoir.example.yml`。

### 3.2 门（全部过 = 收；任一 FAIL = 不收，dig 记录原因）

1. **完整性**：4 实验失败 0；串行=并行 events_hash 抽验 ≥20 局全等。
2. **产物**：报告包四件（md/html 内嵌 + csv/json）+ 回放样本；`SIM_INTERPRETATION_NOTE` 自动继承。
3. **阴性对照门**：刀 C |ΔWR| 的 bootstrap CI **覆盖 0**。不覆盖 → 噪声底可疑，整资产不收。CI 计算路径：若 `bfsim sensitivity` 输出已含成对 CI 则直接用；若不含，用 `.kimi-code/` 只读证据脚本对 `results/v2-swap-dragapult.db` 按种子成对重算（bootstrap 10k，钉死种子）——属证据脚本，非产品代码变更。
4. **表述门**：结论只限「同模拟器内敏感性」，零真实预测措辞。
5. **回归门**：`ruff check .` 零告警 + `pytest -q` 全量绿（应零变化）。
