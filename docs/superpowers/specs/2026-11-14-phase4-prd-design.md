## 2. M14 —— 冠军级卡组评估闭环（A 线）

**动机**：Pass 2 结论——卡组评估可达且原料齐，缺产品层。直接服务年底高级赛。

**任务拆分**：
- **task 123 · metamages 式选卡器**（`battlefrontier/report/field_pick.py` + CLI，**已交付，v0.2 修订后**）：
  - 输入：目标 field 分布（CN 使用率快照，来自上游 `stats usage` 快照文件）+ matchup 矩阵（三层合成：intl 窗真实格 / sim 同口径补全 / 缺口格 low_confidence）；
  - 计算：每候选卡组期望胜率 = Σ share×matchup（**镜像局纳入**，源缺镜像自然剔除）；蒙特卡洛 field 模拟（钉种子 Dirichlet 抖动，输出期望胜率分布与登顶率）；
  - **v0.2 数据纪律**：真实格 n<20 经验贝叶斯收缩（复用 task 110 PAIR_MIN_N 纪律）；intl 格成对一致（主格与镜像格同 source）；每行「真实格贡献%」来源构成列 + 缺格 field 占比 ≥20% 标 ⚠数据不足；field 快照与 intl 窗口错位 >28 天告警；
  - 输出：排序表 + 限定语三行头注（国际窗格 = 弱参照、sim 格 = 同模拟器内）。
- **task 124 · 败局解剖产品化**：任意实验一键产出「终局类型 × 死亡回合分桶 + 每桶抽样回放链接」，进 `bfsim report` 新分节 `--autopsy`；复用 task 120 快照与 task 122 决策理由。**验收（v0.2 修订）：分桶与 game_over 事件一致性的自动化断言；人工核销按项目惯例另列，不进预注册判据**。
- **task 125 · matchup 快照导出器（v0.2 重定边界）**：`bfsim matchup-snap` 导出选卡器可读的矩阵快照（intl 真实格 + n 门槛收缩 + low_confidence 标注 + 窗口时点元数据 + 限定语头注）；不再与 field-pick 内联逻辑重复。

**预注册验收标准**（v0.2）：
1. 给定 2026-10 窗 field 分布，选卡器输出 9 池排序 + 来源构成 + 期望胜率分布，数值可手算复现（抽样钉种子）；
2. 败局解剖分桶与 game_over 事件一致性自动化校验通过；人工核销另列；
3. 全部新输出带限定语，claims register 新增一行（可宣称：「给定 field 分布的卡组选择参考（含来源构成与数据充分性标注）」）；
4. 全量 pytest 绿 + ruff 零告警；**零 Agent/DSL/引擎行为变更**（纯新增报告层）。

**Gate（v0.2 操作化）**：Owner 用真实备赛决策验证一次——**判据：选卡器 top-3 与 Owner 独立判断交集非空，或 Owner 明确记录排序差异的归因**（数据源问题 / field 假设不同 / 工具缺陷）；记录归因后可用才进 M15。

## 3. M15 —— 策略评估第一跃升（B1 试点）

**动机**：Pass 2 盲点 B1/B2——M11 评估器从未接入搜索引导；先小步验证「价值网进 MCTS」再决定是否开 B2 主注。

**任务拆分**：
- **task 126 · 价值网进搜索**：MCTS 树策略接入 `eval-linear-v1.json`（value-informed 子节点选择 + 深度截断已有）；numpy runtime 纪律不破；开关 `value_guide` 默认关，实验定义显式开。
- **task 127 · Elo 联赛基础设施**：agent 种群注册表（YAML）+ 成对对战调度（CRN）+ Elo/TrueSkill 计算 + `bfsim league` 报告；这是 M16 的评估面前置。

**预注册验收标准**（判据冻结于跑批前；**成本门经 Owner 2026-11-14 拍板放宽**）：
1. **净效应门**：`value_guide=on` 的 MCTS（2×50 同预算）对启发式 agent 池，在 ≥3 个指定格上 CRN 成对净胜率 CI 下界 > 0；**加评一档 4×100 深预算格**（价值引导的预期优势区间）；
2. **成本门（放宽后）**：单局墙钟 ≤ 基线 MCTS ×3（原 ×1.5）；深预算档另计、不设倍数门；
3. **行为门**：同种子开/关 `value_guide` 的 events_hash 等价（观测事件口径，task 122 纪律）；
4. 联赛：同注册表同种子重跑 Elo 序一致（确定性）；全量绿 + ruff。

**Gate**：过门 = B2 立项依据 +1（与 Pass 2 探针、task 097 合看）；不过门 = 价值网路线留档关闭，B2 改以 BC 为主入口。

## 4. M16 —— 上位赛事级策略（B2 主注，研究投注）

**动机**：Kaggle 上位公开解验证的路径（BC+RL+MCTS 混合栈）；承诺「显著超越启发式」，不承诺字面冠军。

**任务拆分**：
- **task 128 · 自对弈数据飞轮**：批量自对弈（启发式/价值网 MCTS/蒸馏学生混编种群）→ 决策点数据集 v2（复用 task 052 采集器；episode 挖掘 = 无限动作级数据源，盲点 B3）；
- **task 129 · BC+RL 混合栈**：BC 自蒸馏（教师 = 种群混合）→ RL 微调（PPO/TrueSkill 奖励，torch dev-only）；资产格式延续 `models/policy-m12-v*` 分派纪律；
- **task 130 · 吞吐决策点（前置 spike）**：R2（多进程 env pool + 小网 rollout）实测吞吐 → 达不到训练门槛则 R1 spike（Rust 核心 + DSL 预编译，验收 = 现有 1726 测试绿 + **events_hash 跨实现逐局等价**）；spike 结论决定 M16 架构走向（Owner 已声明可接受重构）；
- **task 131 · 对手建模/剥削层 v1**（可选纳入）：基准策略 + 对手倾向画像（从结果库 replay 提取）+ 偏离建议报告——**输出为策略评估，不自动执行**（遵守 AI 永不非法操作与不越权纪律）。

**预注册验收标准 + kill criteria**（**成本门经 Owner 2026-11-14 拍板放宽**）：
1. **提升门**：混合栈 agent 在 Elo 联赛对启发式净胜 CI 下界 > 0，且相对 M15 价值网 MCTS 中位 Elo 差 > 0（CRN 覆盖）；评测可加跑深预算档；
2. **成本门（放宽后）**：训练一次完整迭代（BC + RL 一轮）单机 ≤ **21 天**墙钟（原 7 天）；推理 runtime numpy-only、单局成本 ≤ 蒸馏学生 ×10（原 ×5；粗筛定位让位，分钟级 → 可接受十分级精排场景）；
3. **Kill criteria**（任一触发即停损）：BC 阶段后联赛对启发式无显著优势（CI 覆盖 0 且点估计 < +3pp）；或 R1/R2 吞吐达不到 BC 训练最低需求且 spike 估期 > **6 周**（原 1 月）；或训练非复算面声明无法维持（D3-4 纪律冲突）。停损后回 M15 水平线，学到的管线资产留档；
4. 资产发布必附效度边界声明（同模拟器内陪练/评估定位），claims register 同步。
