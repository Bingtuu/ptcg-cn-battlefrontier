# task 031 · M7 偏差归因（|Δ|≥25% 格三因素分解）

- 状态：完成（2026-10-03）
- 关联：二期 PRD（`docs/superpowers/specs/2026-10-03-phase2-prd-design.md`）§3.1 / 里程碑 M7；M6 基线 `results/m6-calibration.db`

## 目标

对 M6 偏差表 |Δ|≥25% 的 5 个无向配对（10 有向格）逐格做三因素归因判定——**Agent 决策 / DSL 实现 / 卡表与环境差**——产出可复算的归因报告与修复清单分类。纯分析任务，零代码变更。

结构先验：赛富豪 sim 侧 8 格全负（sim WR 9.5%–39.7%），指向**卡内因素**（Agent 驾驶或 DSL 缺陷）而非对局特异性；苍响 sim 侧对赛富豪/猛雷鼓/喷火龙大比鸟/多龙黑夜魔灵四格偏强，需判定是苍响偏强还是对手偏弱。

## 验收标准（M7）

1. 上表 5 配对逐格给出三因素判定 + 证据（数字可经 `bfsim report --decisions` / 事件流查询 / db SDK 重放）。
2. 修复清单分类输出：Agent 规则项（进 M8 候选）/ DSL 缺陷（独立修复 task）/ 卡表差不可修项（如实标注）。
3. D2-3 门控结论：Agent 因素是否解释 ≥半数大偏差格 → MCTS 是否立项（M8）的建议。
4. 归因报告落 `docs/m7-attribution-report.md`，meta 回显基线锚点（种子区间 / 代码版本 / 数据版本 / 真实侧口径哈希）。
5. 全程零代码变更；不新跑大规模实验（对照小实验 ≤500 局/组允许，须可复算落库）。

## 方法（二期 PRD §3.1 登记口径）

1. `bfsim report <id> --decisions --results results/m6-calibration.db` 决策聚合：关键决策点选择分布 × 胜率。
2. 事件流回放抽查：render 人类可读回合记录，对照真实赛事典型打法。
3. 对照实验分离卡表差：variants 既有设施（换卡表不换 Agent）；必要时小规模补跑（落 `results/m7-attribution.db`）。
4. DSL 单卡复核：嫌疑卡（赛富豪ex 淘金潮/嘉奖硬币、赫普的苍响ex 等）对照 db text_raw 与单卡测试。
