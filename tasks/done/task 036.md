## 设计决议（D-036-x）

- **D-036-1 纯分析主口径**：零代码变更；证据全部来自既有实验库（m6-calibration / m9-recalibration / m8c-mcts / m8c-budget-ladder / m8c-spread），数字可原样重放（可复算硬规矩）。

- **D-036-3 沙奈朵格双侧 MCTS 复核**：赛富豪×沙奈朵（M9 最大偏差格，task 035 单侧残余 -12.9pts）双侧均挂 MCTS @2×50，500 局同种子区间 102500..102999——回答残余是否来自对照侧 heuristic 沙奈朵的操作质量（单侧口径已知局限 D-035-3）。
- **D-036-4 归因记录格式**：每格一条「基线 Δ → MCTS 后 Δ → 归因结论（Agent 策略深度 / 人类操作差 / 卡表异质 / 环境差）→ 证据实验 id」；|Δ| 20~25% 档格附注外推标注。
