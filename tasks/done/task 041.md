# task 041：MCTS 修复后复核（task 039 口径分界后的定量对照）

来源：task 039 修复 MCTS 信息泄漏（挂起根真实隐藏区 rollout + setup 期背面布阵）
后，D-039-4 标注口径分界——历史 MCTS 数字带「半先知」成分（泄漏只让 MCTS 偏强）。
本 task 回答：**修复后 MCTS 还压不压得准真实胜率？** 若仍命中 → M10 归因闭环
变硬；若掉点 → 原结论部分靠泄漏撑着，需重估。

## 设计决议

- **D-041-1（对照设计）**：同实验定义、同种子区间（102500..102999）、同预算档
  （2×50 标准档），唯一变量 = MCTS 代码口径（task 039 前后）。结果落新库
  `results/m11-postfix.db`，旧库 `m10-double-mcts.db` / `m8c-spread.db` 不动。
- **D-041-2（复核格选择）**：①沙奈朵×赛富豪双侧 MCTS 500 局（M10 头牌证据，
  旧口径 63.8% vs real 65.1%）；②赛富豪弱侧单侧 MCTS 500 局（task 035 口径，
  旧 52.2% vs real 65.1%）。
- **D-041-3（判定口径）**：Wilson CI 重叠即「仍命中」；掉点 >CI 半宽则记为
  泄漏依赖成分并量化（旧-新差值即泄漏贡献上界）。

## 验收标准

1. 两组各 500 局零失败落库。
2. 新旧口径对照表产出（sim 新/旧/real 三方 + CI）。
3. 结论落账 STATUS.md：修复后是否仍命中、泄漏贡献量化。

## 结果（2026-10-06 跑批完成，500/500×2 零失败）

| 格 | 旧口径 | 新口径 | real | 判定 |
|---|---|---|---|---|
| 双侧 MCTS（赛富豪视角） | 63.8% | 62.0%（CI 57.7..66.1） | 65.1% | ✅ CI 覆盖，仍命中 |
| 单侧弱侧 MCTS | 52.2% | 51.8%（CI 47.4..56.1） | 65.1% | Δ-0.4pts 噪声级 |

**结论**：泄漏贡献 = 双侧 1.8pts / 单侧 0.4pts，均在 CI 半宽（±4.3）内 = 噪声级；
M10 归因闭环修复后成立且更硬。结果库 results/m11-postfix.db。
