## 研究问题（验收对象）

- **Q1 目标函数**：学习目标是「打赢」（self-play 强度）还是「像人」（拟合 meta）？
  证据链：M8c 预算标定（MCTS 或超人类均值）/ M10 归因闭环 / task 046 D-046-5
  （双门槛过线但复校准 |Δ| 恶化）。给出裁决建议 + 对项目北极星（卡组强度测试
  贴合真实 meta）的影响分析。
- **Q2 范式选型**：候选不少于——①expert iteration（MCTS 教师蒸馏，task 042
  mcts_consider 访问分布已入流）；②学得评估器接入 MCTS rollout 截断/候选排序
  （task 046 死维度 = 现成插槽；M8c 结论「瓶颈在 rollout 质量」的直接对症）；
  ③端到端 self-play RL；④模仿学习（无人类 replay 数据源，预期排除但须写明理由）。
  逐候选过约束矩阵（下方 Q4）+ 预期收益论证。
- **Q3 样本成本测算**：基于既有实测（M6 启发式吞吐 18,000 局/6m15s @16 workers；
  M8c MCTS 标准档 ~135s/局/worker；task 037 优化后口径）外推各范式的数据生成
  墙钟成本；明确「单机可承受」的数量级边界。
- **Q4 硬约束兼容性**：种子确定性 / 可复算三锁定 / 无外部服务 / 不引重型依赖
  （方向 B 非目标排除学习框架——若引入须显式推翻并给理由）/ 信息纪律（可见视图）。
  逐候选判定兼容/有条件兼容/冲突。

## 结果与遗留

- **结论：有条件可行，两步走**——报告 `docs/superpowers/specs/2026-10-16-learning-agent-feasibility.md`：
  M-A 学得评估器接 MCTS rollout（先行小成本验证，10 万局数据 ≈35min，numpy 级实现）→
  M-B MCTS 行为蒸馏（主线，教师数据采集 ~23.4h 一次性，目标 = MCTS 口径例行化非超人强度）；
  端到端 self-play RL 与模仿人类学习判否（样本成本/目标函数不适配、无 replay 数据源）。
- **Q1 目标函数结论**：学习线验收锚 =「拟合 MCTS 教师 + 复校准 |Δ| 不回归」双锚，
  ELO/胜率只作过程指标（证据链：M8b/M8c/M10/task 046 D-046-5 倒 U 关系）。
- **用户裁决（2026-10-16）**：①采纳结论，**立项三期**（M-A 先行）；②torch dev-only
  依赖开口**推迟到 M-B 立项再定**（M-A 不需要）。
- **验收**：6 条全过——报告落盘四问全答 / 成本测算表带出处 / 约束矩阵逐格判定 /
