## 跑批步骤

1. **教师快照采集**（定点格先行，D-M11-6）：pair-34 赛富豪×赫普的苍响 +
   pair-5 沙奈朵×赛富豪，教师 2×50 纯搜索，`--seed-start 500000`
   （训练区间 300000–400799 之外，零重叠）；每格局数按一致率统计功效定
   （目标 ≥1000 分母决策点/格，预计 100–200 局/格，主会话按吞吐实测定）
2. **一致率扫描**：K ∈ {5, 10, 15, 20} × 预算 ∈ {2×25, 1×50, 1×25} = 12 配置
   × 2 快照集；每配置输出一致率 + 附录计数 + 成本（墙钟/决策点）
   ——产出一致率-成本曲线；agreement 若单进程过慢可加 workers（新增须确定性
   测试护航）
3. **选档**：按「一致率 ≥0.85 的最低成本档」选定候选配置（无档达 0.85 → 如实
   落账并按设计 §5 评估修订，不强行过验收）
4. **定点格 CI 锚**：候选配置在 two 定点格跑胜率（种子区间对齐 M8c 口径），
   95% CI 须覆盖 2×50 基准实测值（基准值从既有结果库查：苍响 MCTS 95.2%、
   沙奈朵×赛富豪格 M10 63.8% 等，落账引用实验 id）
5. **M11 报告**：`docs/m11-learned-evaluator-report.md`——一致率-成本曲线 +
   特征重要性（权重绝对值排序，task 051 已产）+ 模型资产锚点（路径 + meta +
   训练数据种子区间/代码版本）+ 附录（分母外决策点计数观察，设计 §5 风险项）

## 验收标准

1. 双锚（D-M11-7）：一致率 ≥ 0.85（12 配置扫描后选档口径）+ 两定点格 CI 覆盖基准
2. 确定性抽验：同一快照文件 + 同配置 agreement 两跑报告逐字段全等；快照采集
   同种子重跑逐行一致（小样本抽验即可）
3. 全量 pytest 绿 + ruff 零告警（harness 若加 workers 须配串并一致测试）
4. 报告 meta 回显：快照 id / 种子区间 / 配置 / 模型资产版本（可复算三锁定）
5. 里程碑验收结论呈报用户（goal 拍板点——呈报后等用户确认再启 M12）

## 实现要点

- 长跑批一律后台；扫描矩阵可先小样本试跑测吞吐再定正式局数
- 一致率若系统性不达 0.85：先归因（分歧集中在哪类行动/哪个 K 档）再回报，
  不调阈值迁就（阈值修订须呈报）
- 冻结面：tune/、learn/、engine/ 零改动；mcts.py / agreement.py / snapshot.py
  只在「加 workers 并行」确有必要时最小改动（须主会话复验）

  （相对天花板均值 100.2%，成本教师档一半，保留双世界 determinization 多样性）

  口径 ≥0.85，选档达成）；锚 2：苍响格 92.6% 独立口径贴边未覆盖 / CRN 成对口径
  覆盖 0（两口径并列呈报）；双学生格 51.4% 两口径一致显著未覆盖（-12.4pts）
  → **锚 2 未达成**，归因快查 = 截断+评估器对后期盘面估值失真（学生局均长
  19.4 vs 21.1，多输局短 3.9 回合；分布漂移实证）
