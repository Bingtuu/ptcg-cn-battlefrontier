## 候选臂（预注册，跑批前钉死）

**Elo 辅助推荐流程**（最小机制臂：价值网尚未存在，Elo 是可零预算测试的同款「评级辅助」机制；value_guide 接入方案不在本实验预设）：

1. Elo 注册表 = {base, L01–L10, C01–C03, 4 opponents}；评分机制 = **Bradley-Terry MLE**（MM 迭代，确定性、无步长超参；Elo 分即 BT 在线估计，MLE 为其收敛极限）。
   - **预注册修正条款（2026-11-16，bug 类，跑批中记录）**：初版实现 = 固定 K=32 顺序 Elo 30 轮；K 扫描实证（K=32/8/2 + BT-MLE 四档）其排序未收敛至自身数据的 BT-MLE（K=32 将 C01/BASE 序倒置，K→0 与 MLE 一致 C01<BASE）——估计子未收敛到它所估计的量，属实现缺陷而非判据变更。修正 = 估计子换 BT-MLE；K=32 读数作为敏感性对照留档，修正前后两版判决并报告。
2. 评分：score(c) = Σ_opp w_opp · E(c, opp)（E 由 BT log-strength 导出），w = field 份额四对手内归一；**等权评分作敏感性对照列**（判定以 field 权为准）。
3. 推荐 = argmax score；**拒绝规则 = score(c) < score(base) 即拒**。

## 预注册判据（数值跑批前冻结）

- **(a) 有害组合检出**：score(C01) < score(base)（「被拒」分支）。「排序低于其两个单刀」分支在 v1 标签集**不可操作**（标签集无单刀臂——C01 的两刀为同一 1-for-1 换两张的两拷贝），记录为规格覆盖缺口，以被拒分支执行。
- **(b) 推荐质量非劣**：top-1 推荐的冻结标签均值 ΔWR ≥ **+3.6pp**（= naive 基线 +4.6 − 1pp 容差；1pp = task 146 标签定义有害阈）。
  - **规格解释记录（预注册声明，非跑后追认）**：PRD 原文「显著优于基线」按字面在 v1 标签集上**构造不可达**——正向上限即 L01 本身（+4.6 = 基线值，不存在显著更优组合）。该表述面向的是「naive 会踩有害组合」的一般场景（其价值在下文 C01 对照中体现），在 v1 标签集上以非劣 + 有害规避操作化，否则判据不可证伪于「不可能通过」方向。
  - **naive 流程的有害类对照（结构性论证，预注册）**：naive = 采纳全部过门单刀、**无组合复核环节**（task 141 v1 事故 + swap-search 设计文档「不可组合外推」限定语）——若 C01 的两刀曾以单刀过门，naive 必然产出 C01（−2.4pp）。本实验实测臂演示：同一评分机制 + 拒绝规则可将其拦截。此为 (b) 的判别价值所在。
- **支撑指标（非门）**：① LOCO 4 折（留一对手胞）：3 胞拟合评分下 C01 仍被拒的折数（期望 4/4）；② 每折 held-out 胞上 {base+13 组合} Elo 预测期望胜率 vs 实际 WR 的 Spearman（期望 >0 折数 ≥3/4）；③ in-sample 全部组合 score 排名 vs 标签均值排名 Spearman。

**判决**：(a)(b) 全过 = **M15 门槛通过**，task 126 按 PRD 原预注册验收标准（净效应门 + 成本门 + 行为门）开发；任一不过 = M15 no-go 留档（处置同 task 097：task 127 不激活、value_guide 维持默认关）。

**不可采信声明（预注册）**：本实验一切 sim 数字 = 启发式自对局结果，不构成真实胜率预测（claims register 守则 1）；本实验测的是**机制判别力**（在地真值上检出有害/排序良性），不是任何外部效度主张——自对局胜率差不列入过门证据（PRD 条款 2）。

**教师裁判锚点处置（预注册）**：可采信证据清单中的教师锚点（决策一致率）需已接入的候选系统才能测量，零预算门槛段不可测——预注册声明其转入 task 126 开发验收（净效应门同批复测决策一致率），门槛段不单独测量。
