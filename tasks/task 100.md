## 目标

M13 full 基线普查（2026-11-02）显示 16 个 |Δ|≥25% 格中：N索行两轴已关闭（task 099），电电虫×多龙半归因（MCTS 敏感但过冲），**猛雷鼓厄诡椪×多龙（±32.3，real n=1057）与 火伊布猫头夜鹰×多龙（±31.0，real n=393）从未归因**。本 task 对这两格做 task 099 同口径的 would-change 频数预检，回答：这两个格的残差里有没有**可通用识别的选择错误**，值得开新刀？

## 预注册设计

- **数据源**：`results/v2-calibration-post086.db`（M13 矩阵局，seed 200000 段，每对 500 局）。
  - 配对 1：deck a=`mik_moe:676249`（猛雷鼓）vs deck b=`mik_moe:677868`（多龙）
  - 配对 2：deck a=`mik_moe:689871`（火伊布）vs deck b=`mik_moe:677868`（多龙）
  - 视角：**输家侧**（玩家 0 = 猛雷鼓 / 火伊布）——sim 显示这两侧胜率 15–19%，是残差的承载方。
- **replay 校验**：逐局比对 `events_hash`，不一致的局剔除并计数（参照 task 099：500/500 一致才可信；该库代码版本 post086 与当前 agent/engine/dsl 无行为差异——task 099 已核 092 库，本库另行验证，若 hash 不一致率 >0 则先停查原因）。
- **识别器（紧口径，全部限合法行动集合内）**：
  - W1t：己方战斗场存在可支付且估算可斩杀对方战斗场的招式，本回合未拿奖。
  - W2：手中有支援者「老大的指令」且支援者槽可出，对方备战区存在可支付可斩杀目标，本回合未拿奖。
  - 不适用项：W3（复制招式斩杀）仅对 N索类复制卡组有意义，这两副牌无复制攻击，不启用。
- **统计口径**：局数 = 至少一个 qualifying 决策点的局；采样门 = 合法行动 kinds 含 `attack` 或 `end_turn` 的主线决策点（照抄 task 099）。与 task 099 **不相同**处（预注册钉死，防口径漂移）：① 基数 = 输家侧全部败局（配对 1 ≈425、配对 2 ≈407），无 touch 分层；② W2 带 `not W1t` 去重（战斗场本回合已可斩杀时不重复计入）；③ 胜/负区分度为硬门而非 sanity 参考；④ 拿奖检测符号翻转——输家侧是玩家 0，判「对方被击倒」用 `knockout` 事件 `player==1`（写反则频数表静默出错，hash 校验不兜底）。W2 沿用 task 099 近似：用己方战斗场最佳可支付伤害评估备战区目标可斩性（假定同一招式可打备战区），属继承近似非新口径。
- **判定规则（预注册，不得事后更改）**：
  - 数学定义：f_loss = 败局中 qualifying 局数 / 败局总数；f_win 同义。区分度 = f_loss ≥ 1.5 × f_win；**f_win = 0 时区分度视为满足**（只看 f_loss）。
  - **建议立项**（按 **配对 × 识别器 各自独立判定**）：f_loss 对应局数 ≥15 **且**区分度满足。
  - **方向关闭**：某配对所有识别器不满足上式 → 该格定性为结构性/无通用 would-change；两格都关闭 → 菜单 D 收敛，输出决策地图后停止。
  - 不二次调参、不追加识别器后再称预注册（防 forking paths）；若全部 FAIL 但对某个信号有强烈残余兴趣，只能作为新一轮预注册的起始假设。
- **成本**：replay 1000 局启发式（约 2–5 分钟墙钟）+ 脚本泛化，零 MCTS。

## 结果与遗留

**结论（预注册判定规则自动生效）：两格 W2 = 立项候选；W1t = 关闭。**

- replay 可信性：两配对各 500/500 events_hash 一致（`1405d2f+dirty` 至今 agent/engine/dsl 零 diff）。
- **W1t（可支付直斩漏拿）方向反转**：败局 30.1–32.4% vs 胜局 49.5–64.0%——「能斩不斩」在领先方更常出现，非输家错误，两格均关闭。
- **W2（老大拉备战斩杀转换）跨两独立卡组复现**：猛雷鼓×多龙 败 51/425（12.0%）vs 胜 3/75（4.0%）= 3.0×；火伊布×多龙 败 47/407（11.5%）vs 胜 4/93（4.3%）= 2.7×。均 ≥15 局且区分度满足 → **立项候选**。诊断：W2 败局点 76% 实际选择 play_trainer（非斩杀用途）。
- 机制解释：`_lethal_attack` 只查对手战斗场，备战区斩杀转换不在视野；`_decide_main` 支援者按 iid 排序无奖杯意识（083/085 击杀前瞻的已知留白）。
