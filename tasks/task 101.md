## 目标

把 task 100 预检通过的 W2 would-change 转成最小启发式门：当手中有「把对手备战宝可梦换到战斗场」的支援者（DSL 结构：`on_play` 含 `action: switch, selector: opponent_bench` 节点——「老大的指令」即此结构，同结构卡一并覆盖）且对方备战区存在可斩杀目标时，优先出该支援者并选择该目标，完成拿奖转换。

## 预注册规则

- **检测（无卡名）**：手中**支援者**卡（`trainer_subtype == "支援者"` 是检测组成条件，非隐含前提——同结构的「反击捕捉器」「顶尖捕捉器」是物品，必须被 subtype 挡在门外，否则 R2 挂起帧判定会被异结构节点干扰），其 DSL 文档（`card_effects` + `doc_for`）任一 `on_play` 效果的动作节点含节点**顶层** `action == "switch"` 且**顶层** `selector == "opponent_bench"`（`selector` 是 ActionNode 顶层字段，不在 `args` 内）。
- **R1（主线优先位）**：`_decide_main` 中位于 attack(lethal) 之后、attach_tool 之前（战斗场本回合已可斩杀时既有 `_lethal_attack` 优先，不抢）。条件全满足才触发：
  1. `boss_conversion_gate` 开；
  2. 手中有检测命中卡 ∧ 其 `play_trainer` 行动合法（支援者槽空）；
  3. 对方备战区存在目标：该目标 `remaining = _ko_remaining(view, mon) > 0` 且 `remaining ≤ 对该目标的有效可支付伤害`（**按目标自身弱点/抗性重算**——用 `_view_as_active` 把备战目标换入 opponent.active 后跑 `_attack_table` + 可支付过滤；伤害词计数类节点随视图拷贝正确读目标，口径与 task 100 预检的「战斗场近似」不同，预期命中频率会偏离 11–12% 的引用数字，属已知漂移）且该招式 **`lethal_ok=True`**（`lethal_ok=False` 的效果条件不可判招式不得作为触发依据）；
  4. 己方战斗场本回合有可支付攻击行动（拉人后要打得出来）。
  动作：返回该支援者的 `play_trainer` 行动（tie：多张命中卡取 iid 最小）。
- **R2（挂起目标选择）**：`pending_choice` 来源效果的当前节点为上述 switch/opponent_bench 结构时，`choose` 池内优先选「可斩杀目标」（同 R1 的伤害口径）；多个取 remaining 最小（最稳的斩杀），再 tie 取 iid 最小；池内无可斩杀目标 → 回落既有选择逻辑。
- **不与 deck_low 抑制冲突**：命中卡无 draw 节点，不受 D-032-6 影响（若未来同结构卡含 draw，按既有 deck_low 规则自然处理，不特判）。
- **消融**：`boss_conversion_gate=False` 时 R1/R2 完全不介入（回到 iid 最小支援者与既有 choose 逻辑），供验证与回退。

## 预注册验证设计

- **种子段**：800000 起（避让 200000/208000/300000–305999/600000–601027/700000–717999/900000）。
- **实验**（全部启发式，双侧同门，零 MCTS）：
  - 目标对 1：`mik_moe:676249` vs `mik_moe:677868`（猛雷鼓×多龙），N=1000/侧（baseline vs gated）
  - 目标对 2：`mik_moe:689871` vs `mik_moe:677868`（火伊布×多龙），N=1000/侧
  - 对照对：`mik_moe:677868` vs `mik_moe:690359`（多龙×N索，已知敏感格），N=500/侧
- **主指标**：两目标对合并的逐种子 A 侧结局差（gated − baseline，+1/0/−1）均值 >0 且 95% CI 下界 >0；且每对点估计 >0（防一对掩盖另一对反向）。
- **对照护栏**：对照对逐种子差 CI 下界 > −2pts（无显著恶化）。
- **全局护栏**：全 v2 矩阵（seed 200000 段，与 M13 基线同种子各跑一遍）加权 |Δ| ≤ 18.065% + 0.5pp 且单格 |Δ| 恶化 < 10pp。
- **判定（预注册）**：主指标 + 两护栏全过 → 合并 main；任一不过 → 回滚 `heuristic.py` 变更与对应测试（保留 task 文档与证据），记录失败数字。
- **稀释分析（TDD 前已实证，2026-11-02）**：B 侧（多龙，带 3 张老大）W2 败局频率 6.7%/9.7%（配对 1/2），绝对量 5+9=14 局 vs A 侧 51+47=98 局——**干预量 7× 不对称偏向 A 侧，双侧同门对 A 侧主指标的稀释有限**。验证仍附 B 侧同口径统计量为 secondary（只报告不进判据，沿 task 099 惯例）。
- **实验配置**：baseline 臂显式 `params: {boss_conversion_gate: false}`（默认开，「现状」靠参数关出）；gated 臂用默认。合并口径 = 2000 种子池化（两对 N 相同，与「两对均值再平均」数值等价）。
- **效应路径知情项**：task 100 诊断显示 W2 败局点 76% 选择了 `play_trainer`——R1（该出老大时改出老大）与 R2（出了老大后选对目标）都是效应载体，实现与解读不预设孰主孰次。
- **成本**：约 45k 启发式局（16 workers 约 20–30 分钟墙钟）+ 矩阵 36k，零 MCTS。

## 结果与遗留

**结论：验证 FAIL，按预注册回滚（2026-11-02）。** TDD 实现本身完整（11 测全绿、全量 1707 passed、零回归），但 CRN 验证未过线。

- **主指标（800000 段，N=1000/侧 × 2 对，失败 0）**：
  - 猛雷鼓×多龙：A 侧 WR base 0.148 vs gate 0.145，逐种子差 mean −0.6pts CI [−1.9, +0.7]
  - 火伊布×多龙：0.172 vs 0.166，mean −1.2pts CI [−2.8, +0.4]
  - 合并池化 2000 种子：mean **−0.9pts CI [−1.9, +0.1]**——点估计为负且 CI 下界 <0 → **FAIL**
- **对照护栏（多龙×N索，N=500/侧）**：mean −3.2pts CI [−7.2, +0.8]，点估计同样为负（下界超过 −2pts 容忍线）→ 亦不过线。
- **全局护栏未跑**：主指标已判 FAIL，按预注册停止条件不再消耗算力。
- **执行回滚**：`heuristic.py` 恢复分支 HEAD（gate 零残留）、`tests/test_heuristic_boss_conversion.py` 删除；实验 yml、CRN 脚本、预检改动保留为证据。

**机制解读（失败教训）**：W2 频数预检的两个门槛（≥15 局 + 胜/负区分度）都过了，但**频数 ≠ 局价值**——干预点集中在「已经落后多个奖」的败局里，单次拿奖转换不足以翻转这类局（对照 gard-zoro 负局 prizes 203/236 的结构）；且 76% 的干预点原本就在出训练家，门改变的是目标/时序而非「从不出到出」，边际收益天然有限。与 task 093（ON 比 OFF 更差）同型：**局部 would-change 信号不自动翻译成胜率**。

**归档意义**：这是 16 大格归因地图中最后一个立项候选的实证闭环。结论链完整——决策点级 would-change 频数（task 100 PASS）→ 门实现（task 101 TDD ✅）→ 局级价值 CRN（task 101 FAIL）。**启发式窄刀时代正式收官**：加权 |Δ|≈18% 的残差属策略整体质量层，剩下的只有更高预算搜索（MCTS，成本已封顶）或接受现状两条路。
