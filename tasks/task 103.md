# task 103 — 校准参考面赛制一致性审计（P1：零信号归因）

- 日期：2026-11-03
- 分支：`task/t103-regulation-audit`
- 性质：**审计 + 判别式验证，零行为变更**（文档 + 只读脚本 + 结果 JSON）
- 动机：task 102 判定「v1/v2 双池格级 sim 信号 ≈ 0」。但读 manifest 时发现校准参考面与模拟环境存在**时间/赛制错配**——若混因成立，「零信号」就不能全部归因于启发式策略质量，判决必须降档。本 task 用上游 db 只读查询钉死这个问题。

## 1. 侦察事实（结构性，先于预注册；上游 db v20261025.1 只读）

| 事实 | 证据 |
|---|---|
| 模拟卡快照 = standard-2026-09-16（J 标，allowed G/H/I/J） | `legality_snapshots` |
| 9 套 sim 牌表全部 2026-09-19 后首次出场，**全部 GHIJ 赛事** | `deck_appearances`⋈`tournaments` |
| **对局级 pairings 数据止于 2025-12-27**（140,965 场，2025-04-11 起） | `pairings`⋈`tournaments` |
| 池选择窗 2026-09-16..10-21（46 场）**只有出场/WUR 层，无对局级结果** | 同上 |
| 校准真实窗 = 2025-04-11..08-31（409 场），早于卡快照约一年 | m13 manifest |
| **结论：赛制对齐校准窗在当前数据下不可构造** | Q2 判定 |

## 2. Q1 牌表-环境错配度（探索性读数，正式数以脚本输出为准）

**卡名级**口径（修正印刷版伪差：sim 表用 30 周年异画印刷，card_id 级重合度 0–28% 是印刷伪差；卡名级才是真实错配度）：

- sim 牌表中 **卡名首次发售日晚于 2025-08-31 的卡位：32%–65%**（9 套全部过半邻近）。
- **核心引擎级错配**：N's Zoroark 的名字引擎线（N's Zorua/Zoroark ex/Reshiram/Darumaka/Darmanitan = 14 卡位）全部 2026-07-16 才存在——「N's Zoroark」这套牌在真实窗口**根本不可能存在**；Marnie's 长毛巨魔线、Charizard 表的铁斑叶/猛雷鼓、Flareon 表的赫月熊等同型。
- **archetype 跨窗连续性分化**（sim 表 vs 真实窗同 archetype 最常见表的卡名重合度）：连续型 {Raging Bolt Ogerpon 92% / Gardevoir 88% / Dragapult Dusknoir 82% / Grimmsnarl Froslass 78%}；断裂型 {N's Zoroark 67%（缺的全是引擎）/ Dragapult 67% / Flareon Noctowl 68% / Charizard Pidgeot 13% / Joltik Box 20%}。

**初步判定：混因 MATERIAL（>10% 卡位 + 核心引擎缺失）**。

## 3. 预注册 Q3 判别式验证（正式，脚本钉死）

### 3.1 方法

- 臂划分（exogenous，不接触胜率数据）：**连续型 = 卡名重合度 ≥ 75%**（4 套：RB/Gard/DD/GF），断裂型 = 其余 5 套。
- **低混因子图**：两端均为连续型的无向对（C(4,2)=6 对，12 有向格）。若 sim 在这些「牌表基本跨窗一致」的对上仍零相关，则混因解释不了零信号 → task 102 结论在这些格上钉死。
- 对照：全 72 格（task 102 基线，Pearson −0.10 / Spearman −0.11 dev）。
- **真实窗半窗稳定性**：真实格胜率前半窗（04-11..06-15）vs 后半窗（06-16..08-31）加权相关——给出「真实格值本身多稳」的参照系。
- sim 侧：m13 development 包（sim 值不随真实窗变化，dev/val 同 sim）。

### 3.2 判定门（预注册）

| 门 | 判据 |
|---|---|
| D1 | 低混因子图加权 Pearson：≥ +0.4 → 「低混因格有信号」（混因解释大部分零信号，task 102 判决降档为「混因污染，搁置」）；≤ +0.2 → 「零信号稳健」（task 102 结论钉死）；0.2–0.4 灰区 → 加报 Spearman 与逐格清单，人工判读 |
| D2 | 半窗稳定性：前半 vs 后半真实格相关 < 0 → 校准参考面本身不稳定，所有格级结论额外降档（含 task 102） |
| D3 | 审计完整性：Q1/Q2/Q3 全部数字脚本复现；重算 real_wr 与 m13 full 包按 real_n 加权平均偏差 ≤ 1pt（单格容差 2pts；包构建后 db 有 v20261025.1 刷新，小格允许漂移） |

### 3.3 处置（无论结局）

- **D1 ≤ +0.2（预期）**：task 102 结论升级为「跨池 + 跨窗稳健」；产品定位维持收窄；另写 backlog：上游 db pairings 延伸至 GHIJ 时代后，用赛制对齐窗重验（唯一能让格级外部效度复活的数据条件）。
- **D1 ≥ +0.4（意外）**：task 102 判决降档为「混因污染、搁置」；「接受现状」决策回炉重议。
- 证据合 main（同 102 范式）；零 `battlefrontier/`/`tests/` 变更。

## 4. 结果（正式验证，2026-11-03）

| 门 | 结果 | 判定 |
|---|---|---|
| D1 低混因子图（12 格，两端连续型，full 包 real） | 加权 Pearson **−0.010** / Spearman +0.001；逐格 sim 大幅偏离真实（Gard vs RB：sim 76.6% vs real 51.8%，牌表重合 88–92%） | **zero_signal_robust**（≤+0.2 门） |
| D1 稳健性：用当前 db 重算 real（包构建后上游有数据修订） | Pearson **−0.010** | 不变 |
| D2 真实窗半窗稳定性 | 前半 vs 后半相关 **+0.664**（66 有向格） | stable（参考面内部稳定） |
| D3 重算-包一致性 | 加权平均偏差 **1.53pts** > 1pt 预注册门 → **D3 按预注册 FAIL**；根因 = m13 包构建后上游 db 数据修订（3 个 v2 新 archetype 格漂移至 6.6pts；子图最大 2.35pts）；子图 D1 用新旧 real 均 −0.010 → 结论不受影响 | FAIL（作为发现记录，见下） |

**最终判定：混因 MATERIAL（Q1：32–65% 卡位 + N's Zoroark 等引擎级缺失；Q2：对齐窗不可构造）但混因解释不了零信号——牌表基本跨窗一致的低混因格上 sim 依然零相关。task 102 结论升级为「跨池 + 跨窗 + 低混因子图稳健」。**

**附带发现（D3 FAIL 的根因，独立价值）**：上游 db 在 m13 包构建后有数据修订（新 archetype 映射级），`results/m13-baseline/` 双轨包的真实侧已偏离当前 db 最多 6.6pts——后续任何用旧包的定量结论引用 real 值时应注明此漂移。

## 5. 处置

- 「接受现状」从推断升级为**钉死**：外部格级效度未建立 = 跨池稳健事实，非数据混因 artifact。
- backlog 追加：上游 pairings 延伸到 GHIJ 时代 → 赛制对齐窗重验（唯一能让格级外部效度复活的数据条件）；db 数据修订 → m13 包按需重建。
- 产品定位维持收窄（对局模拟 + 决策分析）。
- 证据合 main（同 102 范式）；零 `battlefrontier/`/`tests/` 变更。
